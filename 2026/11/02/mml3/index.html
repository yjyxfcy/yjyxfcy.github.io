本篇是北京大学《多模态学习》（2026 秋）期中考试速通笔记的配套练习，汇集课程知识点相关的选择、判断、计算和简答题，并附参考解答。每道题下紧跟参考答案与解析，可以先遮住答案独立作答，再核对推理、公式和边界条件。适合与多模态学习概览和公式与计算配合阅读。

一、选择题（单选）

1. 下面哪项最准确地描述多模态“对齐”？

A. 将多个模型输出取平均　B. 找到图中区域和句中词的对应　C. 从文字生成图像　D. 随机丢弃一个模态

答案：B。 对齐找局部对应，A 是晚期融合、C 是转换。

2. 纯线性层连用三层、层间无非线性，整体相当于：

A. 一个线性/仿射映射　B. 一个任意非线性函数　C. 一个 softmax　D. 一个卷积核

答案：A。 矩阵复合仍是线性/仿射。

3. 对 NCHW 图像激活做标准 BatchNorm，固定通道 $c$ 时均值主要沿哪些轴求？

A. 仅 C　B. N、H、W　C. 仅 H、W　D. C、H、W

答案：B。 固定通道，在批与空间轴统计。

4. 关于 ReLU 和 Leaky ReLU，正确的是：

A. ReLU 在所有位置有非零梯度　B. Leaky ReLU 负半轴有小斜率　C. Leaky 的斜率一定可学习　D. 两者输出都限制在 $(0,1)$

答案：B。 Leaky 的负斜率固定；PReLU 才学习斜率。

5. 深度可分离卷积的两步通常是：

A. 先 $1\times1$，再池化　B. 先逐通道空间卷积，再 $1\times1$ 跨通道卷积　C. 两次 FC　D. 先图像描述，再文本分类

答案：B。 Depthwise 空间处理 + pointwise 通道混合。

6. Faster R-CNN 相对 Fast R-CNN 的关键改动是：

A. 取消所有分类　B. 用 RPN 学习候选区域　C. 每框单独跑 CNN　D. 改成语义分割

答案：B。 RPN 替代外部候选方法。

7. RoI Align 对比 RoI Pooling 主要缓解：

A. 坐标量化造成的位置错位　B. 类别数过多　C. 语言模型暴露偏差　D. 梯度裁剪问题

答案：A。 浮点坐标与插值减轻量化错位。

8. 以下哪个是 YOLOv1 在 $S\times S$ 网格、每格 $B$ 框、$C$ 类时的输出标量数？

A. $S(5B+C)$　B. $S^2(5B+C)$　C. $B^2(S+C)$　D. $S^2BC$

答案：B。 每格 $5B+C$，共 $S^2$ 格。

9. CBOW 的训练方向是：

A. 给中心词预测上下文　B. 给上下文预测中心词　C. 给图像预测框　D. 给两个矩阵求 CCA

答案：B。 CBOW：上下文到中心。

10. Bigram 假设下预测 $w_t$ 使用：

A. 仅 $w_{t-1}$　B. $w_{t-2},w_{t-1}$　C. 全部历史　D. 后一个词 $w_{t+1}$

答案：A。 Bigram 只看前一个词。

11. LSTM 中直接将旧记忆和新候选相加形成新记忆的式子是：

A. $c_t=f_t\odot c_{t-1}+i_t\odot\tilde c_t$　B. $h_t=f_t+h_{t-1}$　C. $c_t=\mathrm{softmax}(QK^\top)V$　D. $o_t=c_{t-1}-x_t$

答案：A。 旧 cell 与新候选相加，受门控制。

12. CCA 的目标最贴近：

A. 找线性投影使两视图相关性最大　B. 让两视图像素逐项相等　C. 只训练图像编码器　D. 最大化模态私有噪声

答案：A。 CCA 优化线性投影后的相关性。

13. CLIP 批内对比目标中，正确配对的图文通常落在相似度矩阵的：

A. 最后一行　B. 对角线　C. 所有非对角线　D. 不构造矩阵

答案：B。 按索引配对时正例在对角线。

14. 若 $Q$ 有 4 个 token，$K,V$ 有 7 个 token，cross-attention 输出有几个 token？

A. 4　B. 7　C. 11　D. 28

答案：A。 输出位置数由 Q 的长度决定。

15. 因果 mask 把未来位置的 attention score 加上：

A. $+\infty$　B. 1　C. $-\infty$　D. 0

答案：C。 softmax 后权重趋于 0。

16. 不加位置编码，self-attention 对 token 重排的基本性质是：

A. 输出严格不变　B. 输出随输入对应重排（置换等变）　C. 自动知道词序　D. 无法反向传播

答案：B。 重排输入，输出相应重排。

17. 原始 BERT 的主要预训练目标之一是：

A. 自回归只预测下一个词　B. Masked Language Modeling　C. 仅边框回归　D. 逐像素实例分割

答案：B。 原始 BERT 的 MLM。

18. LoRA 对 $d_o\times d_i$ 的矩阵使用秩 $r$ 增量，忽略 bias 时新增可训练参数为：

A. $d_od_i$　B. $r(d_o+d_i)$　C. $r^2d_od_i$　D. $d_o+d_i$

答案：B。 两个因子分别 $d_o r$、$r d_i$。

二、判断题（写“对/错”并指出关键条件）

J1. “通用近似定理保证一个有限网络在有限数据上训练得到最优且泛化良好。”

答案：错。 近似能力不保证可训练性或泛化。

J2. “在 CNN 的 BN 中，推理一般沿用训练阶段累计的统计量。”

答案：对。 训练统计量累计，推理常用 moving statistics。

J3. “$L_1$ 正则通常比 $L_2$ 更易使部分权重精确为零。”

答案：对。 $L_1$ 更易稀疏。

J4. “卷积层每个空间位置都学习一套完全不同的核参数。”

答案：错。 卷积核空间共享参数。

J5. “池化层通常没有可学习参数，但会改变特征图空间尺寸。”

答案：对。 普通 max/avg pool 无训练参数，通常下采样。

J6. “U-Net 同尺度跳连通常把编码器特征拼接到解码器；ResNet 经典残差支路通常逐元素相加。”

答案：对。 U-Net 常拼接，ResNet 经典形式相加；具体变体可不同。

J7. “无重叠的两个框其 IoU 为 0，因此 IoU loss 在此位置不提供有效的分离方向定位信号。”

答案：对。 分离框 IoU 局部不提供有用距离信号。

J8. “YOLO 推理时必须先知道预测框和真值框的 IoU，才能给出类别分数。”

答案：错。 推理没有真值框。

J9. “CBOW 的 softmax 输出天然是一个只有一个 1 的 one-hot 向量。”

答案：错。 softmax 是概率分布。

J10. “训练时 teacher forcing 使用真实上一步词，推理时通常没有真实上一步词。”

答案：对。 此差异带来 exposure bias。

J11. “截断 BPTT 越短，越能完整学习任意长度的长期依赖。”

答案：错。 反传窗口过短会截断长程梯度。

J12. “CLIP 的批内负例中，可能有语义相同却未标注配对的假负例。”

答案：对。 批内非配对不必然语义无关。

J13. “$I(X;Y)=H(X)-H(X|Y)$；若独立则互信息为零。”

答案：对。 互信息的等价式与独立性质。

J14. “Cross-attention 的 Q、K、V 必须来自同一序列。”

答案：错。 Cross-attention 中 Q 与 K/V 来源不同。

J15. “ViT 缩小 patch 会增加 token 数，并可能显著增加全局注意力成本。”

答案：对。 token 增多，分数矩阵元素约按长度平方增。

J16. “GQA 把多个 query 头分组共享 K/V，可降低 KV cache 的该部分开销。”

答案：对。 共享 K/V 减少缓存该部分。

三、计算题（附完整过程）

C1. 卷积与池化　输入单张 $3\times32\times32$ 图像，卷积 $5\times5$、输出 16 通道、padding 2、stride 1，带 bias；随后 $2\times2$、stride 2 最大池化。求两层输出形状、卷积参数量、MACs、卷积输出的 FP32 激活大小（KiB）。

解答： 卷积高宽 $\lfloor(32+2\cdot2-5)/1\rfloor+1=32$，形状 $16\times32\times32$。参数 $16(3\cdot5^2+1)=1216$。MACs $32^2\cdot16\cdot3\cdot25=1,228,800$。输出激活 $16\cdot32^2\cdot4/1024=64$ KiB。池化后 $16\times16\times16$。

C2. BN 与 Dropout　固定一个通道，批及空间维合起来有四值 $(1,3,5,7)$。取 $\epsilon=0$、$\gamma=2,\beta=1$，求第一个值标准化及仿射后的结果。另有输入 6，倒置 dropout 丢弃率 .25，若被保留，输出为多少？

解答： 均值 4，方差 $[(1-4)^2+(3-4)^2+(5-4)^2+(7-4)^2]/4=5$。第一个值 $\hat x=-3/\sqrt5$，输出 $y=1-6/\sqrt5\approx-1.683$。保留的 dropout 输出 $6/.75=8$。

C3. IoU + NMS　$A=(0,0,4,4)$、$B=(2,2,6,6)$，连续坐标面积定义，求 IoU。若 A 分数 .9，B 分数 .8，另一个 C 分数 .7 且 $\mathrm{IoU}(A,C)=.1,\mathrm{IoU}(B,C)=.1$，NMS 阈值 .1（按“严格大于阈值才删除”），保留哪些？

解答： 交集 $[2,4]\times[2,4]$ 面积 4；并集 $16+16-4=28$，IoU $1/7\approx.143$。NMS 先保留 A，B 的 IoU $.143>.1$，删 B；C 与 A 是 $.1$，题设“严格大于”才删，所以保留 C。答案 A、C。若题目使用“$\ge$ 阈值删除”，边界结果不同，先看规则。

C4. YOLOv1 与转置卷积　$S=7,B=2,C=20$ 的输出标量数？一个转置卷积 $H_i=4,K=3,S=2,P=1$，无 dilation/output padding，输出高多少？

解答： $49(10+20)=1470$；转置卷积输出 $(4-1)2-2+3=7$。

C5. 语言模型　Bigram 模型给 $P(\text{我})=.2$、$P(\text{爱}\mid\text{我})=.5$、$P(\text{你}\mid\text{爱})=.4$。求“我 爱 你”的概率。若三个位置正确词概率均为 $.5$，困惑度是多少？

解答： 句子概率 $.2\cdot.5\cdot.4=.04$。PPL $=\exp[-\frac13(3\ln.5)]=2$。

C6. LSTM　已算出 $f=.8,i=.25,o=.5,\tilde c=.4,c_{t-1}=.5$，求 $c_t$ 和 $h_t$（$\tanh(.5)\approx.4621$）。

解答： $c_t=.8(.5)+.25(.4)=.5$；$h_t=.5\tanh(.5)\approx.23105$。

C7. 融合与互信息　$a=(2,3),b=(4)$，写出增广外积 $[1;a][1;b]^\top$。公平二元随机变量 $X$ 与 $Y=X$，以 bit 为单位求 $H(X),H(Y|X),I(X;Y)$。

解答： $[1;2;3][1,4]=\begin{bmatrix}1&4\2&8\3&12\end{bmatrix}$。$H(X)=1$ bit，给定 $X$ 完全知道 $Y$，$H(Y|X)=0$，$I(X;Y)=1$ bit。

C8. CLIP　两对图文的相似度 logits 为 $S=\begin{bmatrix}\ln3&0\0&\ln3\end{bmatrix}$，第 $i$ 张图与第 $i$ 段文配对，求双向平均交叉熵。

解答： 每行/列对角正确概率 $e^{\ln3}/(e^{\ln3}+e^0)=3/4$；两方向各为 $-\ln(3/4)=\ln(4/3)$，平均仍 $\ln(4/3)\approx.288$。

C9. 注意力　一个 query 对两个 key 的已缩放 logits 是 $(0,\ln3)$，对应 values $(2,0),(0,4)$。求权重及输出。若第二个 key 被 mask，输出改为多少？

解答： softmax $(0,\ln3)$ 得 $(1/4,3/4)$；加权 $(1/4)(2,0)+(3/4)(0,4)=(.5,3)$。mask 第二个后权重 $(1,0)$，输出 $(2,0)$。

C10. ViT、LoRA、GQA　$224\times224\times3$ 图像以 $16\times16$ patch 切分并加一个 CLS token：patch 数、每 patch 展平长度、序列长度和单头 attention score 元素数？$4096\times4096$ 权重用秩 8 LoRA：可训练因子参数数和占原矩阵比例？若 32 个 query 头、8 组 K/V 头，每组 K/V 供几个 query 头共享？

解答： $N=(224/16)^2=196$；每 patch $16^2\cdot3=768$；序列 197；score 矩阵 $197^2=38,809$。LoRA $8(4096+4096)=65,536$，全量 $4096^2=16,777,216$，比例 $0.390625%$。每 $32/8=4$ 个 query 头共享一组 K/V。

C11. 二分类损失　一个样本二分类 logit $z=0$、真标签 $y=1$。求 sigmoid 概率、BCE 损失和对 logit 的梯度。若 $z$ 增大一点，损失倾向上升还是下降？

解答： $p=\sigma(0)=.5$；$L=-\ln .5=\ln2\approx.693$；$\partial L/\partial z=p-y=-.5$。增大 $z$ 会提高正类概率，局部使损失下降。

C12. 多头注意力维度与参数　序列长 $T=5$、$d_{\rm model}=64$、头数 $H=4$，每头 $d_k=d_v=16$。求每头分数矩阵形状、四头拼接后的每 token 维度；若 Q/K/V 与输出投影均为 $64\times64$，忽略 bias，总参数数是多少？

解答： 每头分数矩阵 $5\times5$；四头输出拼接后每 token $4\cdot16=64$ 维。四个完整投影共 $4\cdot64^2=16,384$ 个参数。这里头数为 4 不意味着每个头都另有 $64\times64$ 的完整 Q/K/V 矩阵；通常将完整投影按头切分。

C13. Precision/Recall　某一置信度阈值下有 $TP=8,FP=2,FN=2$。求 Precision、Recall；解释为什么不能把其中一个数直接当作 AP。

解答： Precision $=8/(8+2)=.8$，Recall $=8/(8+2)=.8$。AP 汇总多个阈值下的 P–R 曲线，单一点不能确定整条曲线。

四、简答题（建议先按“动机—方法—效果—局限”列提纲）

S1. 比较 R-CNN、Fast R-CNN、Faster R-CNN 在候选区域来源、共享特征、训练和速度方面的差别。

参考要点： R-CNN 用 Selective Search 提候选且每框独立 CNN，重复计算重；分类与回归训练较分散。Fast R-CNN 整图只算一次特征，在 feature map 上 ROI Pooling，联合分类/回归，但候选仍外部产生。Faster R-CNN 用共享特征上的 RPN 学候选，后接 ROI head，四类损失可联合训练。速度提升来自共享计算和可学习候选；两阶段检测仍要进行候选处理。

S2. 为什么 CNN 要用非线性、池化/下采样和残差连接？三者分别解决什么问题？

参考要点： 非线性使堆叠层可表达非线性函数，否则多层等价一层。池化/下采样缩小空间尺寸，节省后续计算、扩大感受野，但丢位置细节。残差 $F(x)+x$ 给深网络提供更直接的信息与梯度通路，缓解深层优化困难；形状不符可投影。三者作用不同，不能互相替代。

S3. 比较 BN、LN 与 RMSNorm 的统计方式和典型使用场景。

参考要点： BN 对每个通道在批与空间轴计算均值方差，CNN 常用，训练和推理统计量处理不同，小批量时估计可能不稳定。LN 对每个样本/token 的特征维统计，不依赖同批其他样本，Transformer 常用。RMSNorm 只除以均方根、不减均值，常见于大语言模型；是否加可学习缩放看实现。

S4. 比较 CBOW、Skip-gram、RNN 语言模型的输入、输出和信息范围。

参考要点： CBOW 输入周围词、预测中心词，简化模型通常平均上下文向量，局部顺序弱。Skip-gram 输入中心词、分别预测周围词，两者都从局部共现学词向量。RNN 语言模型逐时刻读前文并预测下一词，隐藏状态可汇总变长前缀；相比固定窗口可利用更长历史，但训练有串行和长依赖困难。

S5. RNN 为何有长依赖困难？LSTM 的门和 cell state 怎样缓解？其局限是什么？

参考要点： RNN 的 BPTT 沿时间反复乘雅可比矩阵，梯度可逐渐缩小或增大。LSTM 用遗忘门保留旧 cell、输入门写候选、输出门决定暴露哪些状态；$c_t=f_tc_{t-1}+i_t\tilde c_t$ 的加法路径有利于较长距离传递。门依赖和 $f_t<1$ 仍可使梯度衰减，不能保证任意长依赖；序列计算仍较难并行。

S6. 用“融合—协调—分解”解释多模态表示学习，分别举一个做法，并比较 CCA 与 CLIP。

参考要点： 融合把模态合成一个表示，如拼接、门控或张量融合；协调分别编码，通过相关/对比损失使配对相近，如 CCA/CLIP；分解把共享和私有因素分开，并用重建/判别/解耦目标约束。CCA 在线性投影上最大化相关，CLIP 用图文双塔、批内双向对比交叉熵学习可检索的向量空间。融合、协调和分解可组合使用。

S7. 解释图像描述中的视觉注意力，并区分 self-attention、cross-attention、因果 mask。

参考要点： 图像描述将图像区域编码为 $v_i$；解码每一步据当前状态对各区域算权重 $\alpha_{ti}$，得到视觉上下文 $\sum_i\alpha_{ti}v_i$，帮助生成当前词。Self-attention 的 Q/K/V 来自同一序列；cross-attention 的 Q 来自解码器或一个模态，K/V 来自编码器或另一模态。自回归的 causal mask 阻止看未来，padding mask 阻止看填充位置。注意力热图能提供线索但不等同于可靠解释。

S8. 比较 ViT、BERT、GPT 的输入、架构、训练目标；再解释 LoRA 和 GQA 各节省什么成本。

参考要点： ViT 把图像切 patch 加位置编码，送 Transformer Encoder，常用分类 token；主要学习视觉表示，较依赖预训练与增强。BERT 用双向 Encoder 与 MLM 学文本表示；GPT 用因果 Decoder 和下一 token 预测生成文本。LoRA 冻结底座，只训练低秩权重增量，节省微调参数和优化器状态；GQA 让多个 query 头共享 K/V，节省推理 KV cache 的相关部分。二者节省的是不同阶段/资源，不能混同。

S9. 用一张“对照表”的口吻区分 SimCLR、DINO、MAE 的自监督信号，并解释何为代理任务。

参考要点： SimCLR 对同一图像做两次随机增强作为正例，批中不同图像作为负例，用对比损失学习增强不变的表示。DINO 让学生对一个视图的输出匹配教师对另一视图的分布，通常不靠显式负样本表。MAE 随机遮住图像 patch，让模型重建被遮区域，课件用 masked patch 上的像素 MSE。代理任务是从未标注数据本身自动构造标签的任务，如旋转预测、图像补全、上色。

S10. 图像描述出现“物体识别正确但关系说错”，应该优先改进什么？比较 BLEU、CIDEr、SPICE 看什么。

参考要点： 如果物体已识别正确，优先改进区域间的空间/语义关系建模，而非只换更强检测器；可用区域图及消息传递表示“谁对谁做什么”。BLEU 主要看 n-gram 精确率，CIDEr 用 TF-IDF 强调有区分度的词组，SPICE 比较场景图中对象/属性/关系元组的 F1。自动分数受参考描述与解析方式影响，不能替代图像事实检查。
