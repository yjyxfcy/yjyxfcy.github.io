分类、检测、分割：三种任务三种输出

任务区别与框的表示

先把三种任务的输出分清：分类输出整图一个类别；检测输出每个物体的类别加边界框；语义分割给每个像素一个类别、但不区分同类的不同实例；实例分割还要把两个同类物体分开。一个框可以用 (x1,y1,x2,y2)(x_1,y_1,x_2,y_2)(x1​,y1​,x2​,y2​)（两角）或 (cx,cy,w,h)(c_x,c_y,w,h)(cx​,cy​,w,h)（中心加宽高）表示，计算前先统一格式，不然 IoU 会算错。

数据集：认名字更要辨任务

课件给了两个检测基准：Pascal VOC 是 20 类、来自 Flickr 的真实图（aeroplane、bicycle、cat、dog、person 等）；COCO 是复杂日常场景里的多目标检测与实例分割，还带图像描述等标注。加上第 3 讲的 ImageNet/ILSVRC（大规模分类、top-5 评价），我记的提醒是：只看数据集名不能决定评分规则，得看它被用在哪一项任务上。

IoU 与 NMS

交并比是检测的地基。给轴对齐框 A=(x1,y1,x2,y2)A=(x_1,y_1,x_2,y_2)A=(x1​,y1​,x2​,y2​)、B=(x1′,y1′,x2′,y2′)B=(x'_1,y'_1,x'_2,y'_2)B=(x1′​,y1′​,x2′​,y2′​)：

w∩=max⁡(0,min⁡(x2,x2′)−max⁡(x1,x1′)),h∩=max⁡(0,min⁡(y2,y2′)−max⁡(y1,y1′)),w_\cap=\max(0,\min(x_2,x'_2)-\max(x_1,x'_1)),\quad h_\cap=\max(0,\min(y_2,y'_2)-\max(y_1,y'_1)), w∩​=max(0,min(x2​,x2′​)−max(x1​,x1′​)),h∩​=max(0,min(y2​,y2′​)−max(y1​,y1′​)),

I=w∩h∩,U=∣A∣+∣B∣−I,IoU=I/U.I=w_\cap h_\cap,\quad U=|A|+|B|-I,\quad \mathrm{IoU}=I/U. I=w∩​h∩​,U=∣A∣+∣B∣−I,IoU=I/U.

手册例题我重算过：A=(0,0,4,4)A=(0,0,4,4)A=(0,0,4,4)、B=(2,2,6,6)B=(2,2,6,6)B=(2,2,6,6)，交集 2×2=42\times2=42×2=4，各面积 16，并集 16+16−4=2816+16-4=2816+16−4=28，IoU =4/28=1/7≈0.143=4/28=1/7\approx0.143=4/28=1/7≈0.143。不相交时 IoU 为 0，完全重合为 1。若评测用含端点的像素面积 (x2−x1+1)(y2−y1+1)(x_2-x_1+1)(y_2-y_1+1)(x2​−x1​+1)(y2​−y1​+1) 结果会不同，按题目约定。

**NMS（非极大值抑制）**去掉重复框：按置信度排序，保留最高分框，删掉与它 IoU 超阈值的同类重叠框，再迭代。手册例：A 分数 .9、B .8、C .7，IoU(A,B)=.6\mathrm{IoU}(A,B)=.6IoU(A,B)=.6、IoU(A,C)=.1\mathrm{IoU}(A,C)=.1IoU(A,C)=.1，阈值 .5，则保留 A、删 B、保留 C。一个我特意标的易错点：NMS 比的是预测框之间的 IoU，不是预测框与真值的 IoU；阈值越低抑制越强。

Precision、Recall、AP、mAP 与 FPS

Precision=TPTP+FP,Recall=TPTP+FN.\mathrm{Precision}=\frac{TP}{TP+FP},\qquad \mathrm{Recall}=\frac{TP}{TP+FN}. Precision=TP+FPTP​,Recall=TP+FNTP​.

手册例：预测里 8 个 TP、2 个 FP，真实有 10 个对象（另 2 个 FN），则 Precision =8/10=.8=8/10=.8=8/10=.8，Recall =8/10=.8=8/10=.8=8/10=.8。按置信度扫阈值得到 P–R 曲线，一类的 AP 是这条曲线下精度的汇总，mAP 再对类别求平均（有的基准还对多个 IoU 阈值平均）。判断 TP 要类别正确、且与尚未匹配的真值框 IoU 达阈值（课件用 IoU>0.5 且类别对），同一真值通常不能让多个框都算 TP。自己补的备注：AP 不等于单个阈值处的 precision，也不等于 IoU；FPS（frames per second）是速度，和 mAP 是不同维度，不能只看速度断言检测质量。

R-CNN 家族：从慢到端到端

检测的两条路与区域提议

课件先摆困难。把检测当回归：每张图要输出的框数不一样（“each image needs a different number of outputs”），输出维度不固定。把检测当分类：对图里很多 crop 分别跑 CNN 判“物体/背景”，但要对每张图的无数 patch 跑网络，太慢。于是课件引出区域提议（region proposals）：先快速找出“可能含物体”的区域（靠颜色直方图、长宽比、闭合轮廓、颜色一致性），Selective Search 在 CPU 上几秒给约 1000 个提议，目标是让真物体区域尽量落在前 K 个提议里。它不是端到端可学的——这点后面 Faster R-CNN 要改。

R-CNN：逐框跑 CNN

课件的 R-CNN（Girshick et al., CVPR 2014）：Selective Search 提候选框，每个框裁剪缩放后分别跑一遍 CNN，再分类和框回归。微调时与真值 IoU>50% 的提议算“物体”、其余算“背景”，batch 128（32 正 96 负）。课件列了它的毛病：训练目标拼凑（softmax log loss 微调 + 事后线性 SVM hinge loss + 事后框回归 least squares），训练慢（84 小时、占大量磁盘），推理慢（VGG16 下 47 秒/图）。慢的根源就是每框都重复跑 CNN。

Fast R-CNN 与 ROI Pooling/Align

课件的 Fast R-CNN（Girshick et al., ICCV 2015）让整图只跑一次 backbone，在共享特征图上用 ROI Pooling 把不同大小的候选区域变成固定形状，再联合分类与回归。但候选框仍来自外部 Selective Search，整条流水线没有端到端学提议（观察到此时性能被区域提议卡住）。

ROI Pooling 的量化误差是这一讲我卡得最久的地方。课件的小例子：输入 8×88\times88×8、要输出 2×22\times22×2、框坐标 [0,3,7,8][0,3,7,8][0,3,7,8]，w=7,h=5w=7,h=5w=7,h=5，7/27/27/2、5/25/25/2 都不是整数，分箱只能取整。课件放大到真实尺度：输入 665×665665\times665665×665，backbone 下采样 1/32 得 20.7820.7820.78，floor 成 20，误差 0.78×32=250.78\times32=250.78×32=25 像素——对小目标这是很大一笔错位。ROI Align保留浮点坐标、用双线性插值采样，消除量化误差，所以更适合 Mask R-CNN 这类像素级任务。自己补一句：它减少量化误差，但不能消除所有误差。

Faster R-CNN 与 RPN

课件的 Faster R-CNN 干脆“让 CNN 自己提提议”：插入 Region Proposal Network（RPN）从特征图预测提议。课件讲 anchor：想象特征图每个点上放一个固定大小的 anchor 框，实践中每点用 K 个不同尺寸/长宽比的 anchor。整个网络联合训 4 个损失：① RPN 分类（物体/非物体）② RPN 回归框坐标 ③ 最终类别分数 ④ 最终框坐标。它是两阶段检测器：第一阶段每张图跑一次（backbone + RPN），第二阶段每个区域跑一次（ROI 裁特征 + 预测类别 + 预测框偏移）。到这儿提议也进了网络，才算端到端。

检测损失：Focal 与 IoU 家族

Focal Loss：压低易样本

课件讲分类损失 Focal Loss（Lin et al., ICCV 2017）。检测里背景框海量且大多易分，普通 CE 会被它们淹没。记 pt=pp_t=ppt​=p（正类标签）或 1−p1-p1−p（负类标签），

FL=−αt(1−pt)γln⁡pt.\mathrm{FL}=-\alpha_t(1-p_t)^\gamma\ln p_t. FL=−αt​(1−pt​)γlnpt​.

调制因子 (1−pt)γ(1-p_t)^\gamma(1−pt​)γ 在 ptp_tpt​ 大（易样本）时很小，把它们的贡献压下去。手册例 αt=1,γ=2\alpha_t=1,\gamma=2αt​=1,γ=2：易样本 pt=.9p_t=.9pt​=.9 权重 (0.1)2=.01(0.1)^2=.01(0.1)2=.01，难样本 pt=.2p_t=.2pt​=.2 权重 (0.8)2=.64(0.8)^2=.64(0.8)2=.64；基准 CE 分别是 −ln⁡.9-\ln.9−ln.9 与 −ln⁡.2-\ln.2−ln.2。自己补的易错点：别只看调制因子忘掉前面的 log⁡\loglog，Focal 是在 CE 上乘一个随难度变化的权重。

IoU loss 与 GIoU/DIoU/CIoU

课件讲回归损失的改进。最直接是 IoU loss=1−IoU\mathrm{IoU\ loss}=1-\mathrm{IoU}IoU loss=1−IoU，但两框不相交时 IoU 恒 0，对“该往哪个方向挪”给不出有用梯度，于是有了三兄弟（设 CCC 为同时包住两框的最小外接框，ρ2\rho^2ρ2 为中心距离平方，c2c^2c2 为 CCC 对角线平方）：

GIoU=IoU−∣C∣−∣A∪B∣∣C∣,DIoU=IoU−ρ2c2.\mathrm{GIoU}=\mathrm{IoU}-\frac{|C|-|A\cup B|}{|C|},\qquad \mathrm{DIoU}=\mathrm{IoU}-\frac{\rho^2}{c^2}. GIoU=IoU−∣C∣∣C∣−∣A∪B∣​,DIoU=IoU−c2ρ2​.

GIoU用外接框里“没被两框覆盖的比例”做惩罚，无重叠时可为负、仍携带方向信息；DIoU（YOLOv4 用）直接惩罚中心距离，收敛更快；CIoU在 DIoU 上再减 αv\alpha vαv 考虑长宽比，一种常见定义是

v=4π2[arctan⁡(w∗/h∗)−arctan⁡(w/h)]2,α=v1−IoU+v,CIoU=IoU−ρ2c2−αv,v=\frac4{\pi^2}\bigl[\arctan(w^*/h^*)-\arctan(w/h)\bigr]^2,\quad \alpha=\frac{v}{1-\mathrm{IoU}+v},\quad \mathrm{CIoU}=\mathrm{IoU}-\frac{\rho^2}{c^2}-\alpha v, v=π24​[arctan(w∗/h∗)−arctan(w/h)]2,α=1−IoU+vv​,CIoU=IoU−c2ρ2​−αv,

带星号的是目标框宽高。loss 常写 1−GIoU1-\mathrm{GIoU}1−GIoU、1−DIoU1-\mathrm{DIoU}1−DIoU、1−CIoU1-\mathrm{CIoU}1−CIoU。我记的层次是：IoU 看重叠、GIoU 补外接框、DIoU 补中心距、CIoU 再补长宽比；细节公式若课堂没要求，优先掌握改进动机。另外不能说 IoU“永远不可导、从来不能作损失”，它在重叠时是可用的。

YOLO：单阶段检测的进化

YOLOv1：网格与输出维度

课件的 **YOLO（You Only Look Once）**是单阶段：一次前向直接出框、objectness 和类别分数，省去两阶段提提议。课件给 v1 的输入输出：448×448×3448\times448\times3448×448×3 进、7×7×307\times7\times307×7×30 出。一般地，S×SS\times SS×S 网格、每格 BBB 个框各预测 (x,y,w,h,confidence)(x,y,w,h,\mathrm{confidence})(x,y,w,h,confidence) 共 5 个量，另给 CCC 个条件类概率，输出标量总数

S2(5B+C).S^2(5B+C). S2(5B+C).

代入 S=7,B=2,C=20S=7,B=2,C=20S=7,B=2,C=20：每格 5×2+20=305\times2+20=305×2+20=30，整图 49×30=147049\times30=147049×30=1470，正是 7×7×307\times7\times307×7×30。这个公式只适用于 v1，不能套到所有 YOLO 版本。负责格由“目标中心落入哪格”决定，所以密集小目标有局限。一个我复习时差点绕晕的点：训练时 confidence 与真值 IoU 有关，推理时没有真值框，用的是模型预测的 objectness 乘条件类别概率，不能再拿“预测框和真值的 IoU”算分数。

YOLOv2/v3：anchor 与多尺度

课件的 YOLOv2 用 DarkNet-19（19 个卷积层）做 backbone，几处改动：类别预测改成每框一个（不再是 v1 的每格共享）、加 Batch-Norm（约 +2%）、用 K-means 聚类引入 anchor box、pass-through 层、多尺度训练，还有高分辨率分类预训练（约 +4%）。YOLO9000 用层级类别结构 WordTree 组织更多类别。YOLOv3 换 DarkNet-53，并在多个尺度上预测，利于处理不同尺寸目标。我记的主线：v1 每格共享类别 → v2 每框类别 + anchor → v3 多尺度，输出形式一直在变。

YOLOv4：bag of freebies

课件的 YOLOv4（Optimal Speed and Accuracy）展示了一堆“bag of freebies”——只增训练成本、不增推理成本的技巧：Mosaic 增强 + Self-Adversarial Training、DropBlock（卷积网络的正规化，整块丢而非逐点）、Label Smoothing。课件反复出现的 YOLO 家族时间线提醒我：各版本的速度—精度权衡要按具体版本和数据集描述，不能拿 v1 的 7×7×307\times7\times307×7×30 去套后面所有版本。

分割：FCN、转置卷积与 U-Net

从滑窗到 FCN

课件讲分割。最朴素的滑窗逐 patch 分类，课件直说问题：极低效，重叠 patch 的计算完全不复用。**Fully Convolutional Network（FCN）**改成在整图上产生空间特征、再上采样成像素预测，复用计算；但课件提醒，在原图尺度上做卷积会很贵，所以要先下采样再上采样。

上采样：max unpooling 与转置卷积

课件给两种网络内上采样。Max unpooling 靠池化时记下的最大值位置，把值放回原处、其余补零。转置卷积用可学习核上采样，基本尺寸公式

Ho=(Hi−1)S−2P+D(K−1)+output_padding+1.H_o=(H_i-1)S-2P+D(K-1)+\mathrm{output\_padding}+1. Ho​=(Hi​−1)S−2P+D(K−1)+output_padding+1.

无 dilation、无 output padding 时是 (Hi−1)S−2P+K(H_i-1)S-2P+K(Hi​−1)S−2P+K。手册例 Hi=4,K=3,S=2,P=1H_i=4,K=3,S=2,P=1Hi​=4,K=3,S=2,P=1：(4−1)×2−2+3=7(4-1)\times2-2+3=7(4−1)×2−2+3=7。一个必须记的备注：转置卷积是可学习上采样，不是一般意义的矩阵求逆，名字里的“转置”指它和卷积的矩阵表示互为转置，别理解成“把卷积逆回去”。

U-Net 家族与收尾

课件的 U-Net 是编码器—解码器结构：左侧下采样、底部瓶颈、右侧上采样，同尺度特征从编码器横向接到解码器、通常按通道拼接，补回下采样丢掉的细节。这点要和 ResNet 分清：U-Net 是拼接（concat），ResNet 残差是逐元素相加（add）。课件给的家族线是 U-Net → 3D U-Net → Attention U-Net → U-Net++ → nnU-Net → TransUNet / Swin-UNETR，能看到从纯卷积到引入注意力、再到接 Transformer 的演化。

我自己的收尾理解是：这一讲把“视觉理解”从整图标签推进到了框和像素，而检测的 R-CNN/YOLO、分割的 FCN/U-Net 用的还是第 3 讲那套卷积零件，只是组装方式和损失不同。课件的“Next”预告了路线：深度学习基础→计算机视觉→自然语言处理→多模态应用。这些视觉编码器到第 8 讲会和语言模型对接，成为多模态基础模型的“眼睛”；而 U-Net 这条线到生成模型里还会以扩散模型骨干的身份再出现。
