多模态任务与问题

1. 多模态学习的地图（课件 1，约 5–10、20–73 页）

模态指信息的表达/感知通道，如图像、视频、文本、语音、音频、动作。多模态系统学习不同模态之间的关系：图文检索把图像和文字映射到可比较的语义空间；图像描述从视觉产生语言；视觉问答用图像和问题共同决定答案；视觉语言导航把观察与指令转为行动。McGurk 效应和噪声环境中的音视频语音识别曲线说明，不同通道会相互影响并互补，不意味着任何融合都一定提升表现。

课件的五个核心问题：

问题 一句话 典型输出/方法
Representation 表示 怎样把不同模态编码成有用的特征？ 融合表示、协调表示、分解表示
Alignment 对齐 哪些局部元素彼此对应？ 图像区域 ↔ 词，视频帧 ↔ 语句
Translation 转换 怎样由一种模态生成另一种？ 图像描述、文生图
Fusion 融合 怎样合用多个模态完成预测？ 情感分类、视听识别
Co-learning 协同学习 怎样让一模态/数据集帮助另一模态？ 知识迁移、弱配对训练

1.1 课件图示里的任务与难点

任务按输入输出辨别（课件 1，20–38 页）：图文检索输入一个模态、在另一模态的候选集合中排序；指代表达定位输入图像和短语、输出对应区域；视觉问答输入图像和问题、输出答案；视觉对话还依赖历史问答；视频问答需利用帧间时间信息；视觉语言导航把视觉观察和语言指令变成动作序列；图像描述是图像到文本，文生图方向相反。同一张图可能支持多个正确描述，评价生成任务不能只看是否逐字匹配某一句标准答案。

视觉为什么难（约 43–50 页）：同一物体可受视角、光照、尺度、遮挡、背景变化影响；不同类别可长得相似，同类内部也差别很大。识别“有什么”与识别“在哪里、彼此什么关系”是不同层次。语言为什么难（约 51–54 页）：词义随上下文变化，歧义、指代、长距离依赖、不同说法表达同义都很常见。多模态再增加“时间/空间不同步、粒度不同、某模态缺失或噪声更大”的问题，因此模型常同时需要表示、对齐和交互。课件将多模态行为概括为冗余、互补、冲突等情形：当一模态可靠度下降，融合权重应该相应变化；冲突信息不能机械平均。

历史线（约 11–19 页）：早期视听行为研究说明人会联合感知；计算时代依靠人工特征和显式对齐；交互时代强调跨模态任务；深度学习时代由编码器学习特征与关系。梳理研究历史时，可关注方法思路如何从人工特征与显式对齐，转向由模型学习跨模态表示和关系。导论后半的应用图可结合输入输出理解。

2. 深度学习基础（课件 2，约 3–52、54–74、76–128 页）

2.1 从线性回归到多层网络

单样本线性层：$\hat{\mathbf y}=W^\top\mathbf x+\mathbf b$；若输入 $d_{\rm in}$、输出 $d_{\rm out}$，则 $W\in\mathbb R^{d_{\rm in}\times d_{\rm out}}$。矩阵习惯也可写作 $XW+\mathbf 1b^\top$，使用公式时先说明数据按行还是按列。

均方误差可写 $\mathcal L(W,b)=\frac1{2N}\sum_{n=1}^N|\hat y_n-y_n|_2^2$。把偏置并入设计矩阵 $\tilde X=[X,\mathbf1]$，若 $\tilde X^\top\tilde X$ 可逆，正规方程给出 $\tilde W^*=(\tilde X^\top\tilde X)^{-1}\tilde X^\top Y$；不可逆时用伪逆或正则化，不能直接求逆。多层纯线性映射仍等于一个线性映射，所以需要激活函数：$h^{(\ell)}=\phi(W^{(\ell)}h^{(\ell-1)}+b^{(\ell)})$。

“通用近似”说明某些足够宽/深的网络能够逼近一类连续函数，不保证给定网络可训练、数据足够、泛化好，也不等于任意函数都能在有限资源下精确表示。

课件 2，7–20 页的 Light Theory 动画：隐藏 Sigmoid 单元 $\sigma(wx+b)$ 当 $|w|$ 很大时形状接近阶跃，阶跃位置约在 $s=-b/w$；两个方向相反的阶跃相减可近似一个局部“矩形窗”，多个矩形窗按不同高度加权求和，像黎曼和一样逐段逼近目标曲线。图里先改变 bias 移动阶跃，再改变输出权重控制台阶高度，所以“多神经元叠加能拼复杂函数”有直观来源。课件列出三个理论版本：足够宽的单隐藏层网络可在适当条件下逼近连续函数；另一类结果用与输入维度相关的有限宽度（图中写 $d+1$）配足够深度；残差网络还有更窄、足够深的近似结果。这些是不同架构/激活/函数类前提下的存在性结果，不应把“单神经元 ResNet”随意套成任何有限网络都万能。

2.2 激活函数：图像、导数和易混点

函数 公式与导数 记忆点
Sigmoid $\sigma(x)=1/(1+e^{-x})$；$\sigma’(x)=\sigma(x)(1-\sigma(x))$ 输出 $(0,1)$；两端饱和、非零中心
Tanh $\tanh(x)=2\sigma(2x)-1$；$\tanh’(x)=1-\tanh^2(x)$ 输出 $(-1,1)$、零中心，但两端仍饱和
ReLU $\max(0,x)$；正半轴导数 1、负半轴 0 便宜、正区间不饱和；负区间可能“死亡”
Leaky/PReLU $\max(\alpha x,x)$ $\alpha$ 固定是 Leaky，学习得到是 PReLU
GELU $x\Phi(x)$（$\Phi$ 为标准正态 CDF）；常用 $\tfrac12x[1+\tanh(\sqrt{2/\pi}(x+0.044715x^3))]$ 近似 平滑门控；与 ReLU 的硬截断不同
Swish $x\sigma(x)$ 平滑且可在负值区给小输出
SwiGLU $(xW_v)\odot\operatorname{Swish}(xW_g)$ 两支投影相乘，门控中用了 Swish

为什么非零中心会影响优化？ 对一层 $z=\sum_i w_ix_i+b$，有 $\partial L/\partial w_i=(\partial L/\partial z)x_i$。若上层输出 $x_i$ 全为正，则同一神经元的各个 $w_i$ 梯度同号；优化轨迹可能“之”字形。注意梯度符号也取决于损失的反传项，不能说“仅由 $x_i$ 决定”。课件激活曲线可用“饱和区斜率接近零”解释梯度消失。

2.3 损失、反传、优化与训练曲线

分类常用 softmax $p_k=e^{z_k}/\sum_j e^{z_j}$ 和交叉熵 $L=-\log p_y$。若 $C$ 类初始化近似均匀，初始损失约 $\log C$。链式法则把末端损失对参数的导数逐层传回；梯度下降 $\theta\leftarrow\theta-\eta\nabla_\theta L$，小批量 SGD 用一批样本的平均梯度，全批量 GD、单样本 SGD、小批量 SGD 不要混叫。批量平均与求和方向相同，但数值相差批量大小，固定学习率时更新幅度不一样。

把任务和损失对上号（课件 2，92–105 页）：回归输出连续值，常用 MSE；二分类可先算 logit $z$，再经 sigmoid 得 $p=\sigma(z)$，二元交叉熵 $L=-y\log p-(1-y)\log(1-p)$；多类互斥分类用 $C$ 个 logit、softmax 与多类交叉熵。Logit 是尚未归一化的分数，二分类中 $z=\log[p/(1-p)]$ 是对数几率。多标签任务可对每类独立 sigmoid，而不是把“多类”与“多标签”混同。参数是由训练更新的权重/偏置，超参数如学习率、批量大小、dropout 率需另选。课件的计算图用局部导数连乘解释反传，遇到分叉节点要把各条路径贡献相加。

优化器关系：普通 SGD 按当前梯度更新；带动量的 SGD 累积历史方向，减少狭长谷地中来回摆动；Adam 按一阶/二阶矩估计调节每个参数的步长。不同优化器不会消除数据与学习率选择的重要性。学习率调度可在训练后期下降；warmup 从较小学习率升起以缓和初期不稳定。课件曲线重在能诊断“发散、震荡、下降慢、过拟合”，不是背某条曲线的精确数值。

看曲线判问题（课件 2 约 54–74 页）：训练损失一开始不降，查数据/标签、初始化、学习率、梯度；损失变 NaN，先查学习率过大、数值溢出；训练好验证差，查过拟合，考虑增强、正则化、早停；训练和验证都差，查欠拟合/优化不足。训练一个极小数据集至近乎零损失是实现检查。学习率过大可震荡，过小下降慢；仅凭曲线不能唯一定位原因。

2.4 正则化与归一化：统计轴与均值

$L_2$ 正则为 $\lambda|W|_2^2$，倾向缩小所有权重；$L_1$ 为 $\lambda|W|_1$，更易产生稀疏权重。Dropout 训练时随机置零部分激活；倒置 Dropout 保留概率 $q=1-p$ 时把保留项除以 $q$，推理时直接使用全部单元。数据增强通过裁剪、翻转、颜色变化等改变训练样本；测试阶段按固定流程预处理。梯度裁剪限制过大梯度，不能从根本上“证明解决”梯度问题。

训练曲线与增强细节：随机裁剪在训练中改变视野，测试时通常固定缩放/中心裁剪；Mixup 把两张图和标签按同一系数线性混合，$\tilde x=\lambda x_i+(1-\lambda)x_j,\ \tilde y=\lambda y_i+(1-\lambda)y_j$；CutMix 用一张图的矩形区域替换另一张图的对应区域，并按保留面积调整软标签。二者都不是把混合图硬标成一个类别。DropPath/随机深度随机跳过残差分支，适用于深网络；与逐元素 Dropout 不同。对视觉/语言/生成模型的归一化选择，主要看统计轴、批量大小和条件控制需求。

设 CNN 激活 $x\in\mathbb R^{N\times C\times H\times W}$：

  • BatchNorm (BN)：每个通道 $c$，在 $N,H,W$ 上统计；训练时用当前批统计量，推理时常用移动统计量。$\hat x=(x-\mu_c)/\sqrt{\sigma_c^2+\epsilon}$，$y=\gamma_c\hat x+\beta_c$。
  • LayerNorm (LN)：每个样本独立，在选定特征维度上统计；Transformer 中通常是每个 token 的 $d_{\rm model}$ 维。与批大小基本无关。
  • InstanceNorm (IN)：每个样本、每个通道，在 $H,W$ 上统计。
  • GroupNorm (GN)：每个样本，将通道分组，在组内通道及 $H,W$ 上统计。
  • RMSNorm：不减均值，$y_i=\gamma_i x_i/\sqrt{d^{-1}\sum_jx_j^2+\epsilon}$。课件也提 AdaLN，核心是条件信号调节归一化后的仿射参数。

易错：归一化后 $\hat x$ 才近似零均值/单位方差；可学习 $\gamma,\beta$ 后的 $y$ 未必如此。BN 的统计轴不是“只对 batch 维”，CNN 中还包括空间轴。LN 在不同任务中具体统计轴需看张量布局。

3. CNN 与分类网络（课件 3，约 3–61、62–101、103–167 页）

3.1 卷积与池化的计算

图像张量 $C_{\rm in}\times H\times W$，$C_{\rm out}$ 个大小 $K_h\times K_w$ 的滤波器；每个滤波器跨越全部输入通道，不同空间位置共享同一组参数。输出高宽：

课件 3，6–12 页的连续动画按“全连接 → 局部连接 → 卷积”读：全连接让一个输出看到整张图，输入图一大就会有海量参数；局部连接让输出只看附近 $K\times K$，利用图像结构，但不同位置仍有不同参数；卷积进一步让同一滤波器在各位置共享参数。比如单通道输入、单个 $10\times10$ 局部核，若有约 4 万个输出位置，不共享时约需 $4{,}000{,}000$ 个核权重，共享时只需 100 个核权重（这里不计 bias）。权重共享隐含“某种局部图案在不同位置可由相同检测器识别”的假设，带来平移等变性；池化/全局汇聚再提高一定平移不变性。等变指输入平移时特征也相应平移，不变指最终输出近似不变，两者不要混同。

$$H_o=\left\lfloor\frac{H+2P_h-D_h(K_h-1)-1}{S_h}+1\right\rfloor,\quad W_o=\left\lfloor\frac{W+2P_w-D_w(K_w-1)-1}{S_w}+1\right\rfloor.$$

一般非空洞卷积 $D=1$，即 $\lfloor(H+2P-K)/S\rfloor+1$。若课件/题目指定必须整除，按其假设；通常库在无法整除时向下取整。每层可训练参数（含 bias）为 $C_{\rm out}(C_{\rm in}K_hK_w+1)$。乘加次数约 $H_oW_oC_{\rm out}C_{\rm in}K_hK_w$；若把乘和加各计一次 FLOP，数值约乘 2，先声明口径。激活显存仅输出、FP32、单样本时是 $4C_{\rm out}H_oW_o$ 字节，真实训练显存还包括输入、梯度、优化器状态等。

池化每个通道独立，无可学习核，常见最大/平均池化。池化降低空间分辨率、减少后续计算、增加后续单元感受野，但精细位置会丢失。最大池化反向传播只把梯度传向该窗口获胜位置；平均池化按平均分配。感受野：堆两个 stride 1 的 $3\times3$ 卷积可达 $5\times5$，同通道宽度参数约 $18C^2$，少于单个 $5\times5$ 的 $25C^2$，且多一次非线性。

3.2 网络谱系：每个模型回答什么问题

网络 核心设计 为什么
AlexNet 卷积、ReLU、池化、全连接；当时依赖大数据与 GPU 深 CNN 在 ImageNet 分类上显著有效；会按层算尺寸、参数、FLOPs
VGG 多个小 $3\times3$ 卷积，间隔 $2\times2$ 池化 用深度与小核增加非线性并控制参数；末端 FC 参数很多
GoogLeNet/Inception 并行不同尺度分支；$1\times1$ 降维；Global Average Pooling；辅助分类器 多尺度处理且节省计算；GAP 对空间求平均而不是“$1\times1$ 卷积”
ResNet $y=F(x)+x$；形状不同时可投影 shortcut 学残差、改善深层优化与梯度路径；shortcut 不是 U-Net 同尺度拼接
Depthwise separable conv 先每通道独立空间卷积，再 $1\times1$ pointwise 跨通道混合 参数从 $K^2C_iC_o$ 降到 $K^2C_i+C_iC_o$（忽略 bias）
大核/动态卷积 更大有效感受野或随输入调节核 课件 RepLKNet 曲线说明大核配合 shortcut、重参数化可训练；并非“核越大一定越好”

图示判读：卷积的局部连接与权重共享使参数不随输入位置数量线性增大；GAP 把每个通道的 $H\times W$ 值平均为一个数；ResNet 的旁路是恒等/投影相加；Inception 各分支的输出在通道维拼接。大核实验受架构、训练设置影响，不单由核尺寸解释结果。

3.3 课件中其余 CNN 结构与实验曲线

$1\times1$ 卷积在同一像素位置混合通道，可升/降通道数，但若不配合空间卷积，单独不能读取邻域空间。Padding 保持边界信息、控制输出尺寸；stride 负责步进与下采样；理论感受野是输出点可能依赖的输入范围，实际有效感受野的贡献通常不均匀。网络早期的高分辨率特征图会带来较多计算，末端大的 FC 层可能有很多参数：参数量、FLOPs、运行延迟、激活内存是不同指标。

Squeeze-and-Excitation（约 100 页）：先对每个通道做全局池化得到通道摘要，再经小网络产生通道权重并乘回特征图，学习“哪些通道更重要”；它主要是通道重标定，不是空间位置注意力。轻量网络（约 103–111 页）：SqueezeNet 的 fire 模块先用 $1\times1$ squeeze 降通道，再并联 $1\times1$/$3\times3$ expand；MobileNet 用深度可分离卷积；ShuffleNet 用分组卷积省计算、channel shuffle 让组间交换信息；EfficientNet 以系统性尺度扩展平衡分辨率、深度、宽度。模型小不必然在任意硬件上更快，需看访存与算子实现。

RepLKNet/动态核图（约 112–132 页）：大核可扩大感受野，课件强调大 depthwise 核、shortcut、训练时的小核重参数化分支；推理时可把可合并的线性卷积分支折叠为一个核。动态卷积让输入内容参与决定特定位置/样本的卷积权重；图中的性能提升不能脱离参数预算和训练设置解释。神经架构搜索（约 165 页）是自动搜索结构/操作组合的思路，目标仍需在性能和成本间取舍。

4. 检测与分割（课件 4，约 3–59、62–103 页）

4.1 分类、检测、分割

分类输出整图类别；检测输出每个物体的类别和边界框；语义分割给每个像素类别，不区分同类实例；实例分割还要区分两个同类物体。目标检测中一个框可用 $(x_1,y_1,x_2,y_2)$ 或 $(c_x,c_y,w,h)$ 表示，计算时先统一格式。IoU $=|A\cap B|/|A\cup B|$。Non-Maximum Suppression (NMS)：按置信度排序，保留高分框，删除与其 IoU 超阈值的同类重叠框，再迭代；阈值越低通常抑制越强。AP 是一类在不同召回水平上的精度汇总，mAP 对类/阈值求平均；题目需说明具体评测定义。FPS 是速度。

数据集认名字、辨任务：ImageNet/ILSVRC 经典大规模图像分类，课件提 top-5 评价；Pascal VOC 常作为早期检测/分割基准；COCO 有复杂日常场景中的多目标检测与实例分割，并有图像描述等标注。只看数据集名不能决定具体评分规则，需看它被用于哪一项任务。

4.2 R-CNN 系列与 ROI

  1. R-CNN：Selective Search 提约两千候选框；每个框裁剪/缩放，分别跑 CNN，分类与框回归独立训练，计算重复且慢。
  2. Fast R-CNN：整图只跑一次 backbone，在特征图上用 RoI Pooling 把不同大小候选区域变固定形状，再联合分类与回归；候选框仍由外部 Selective Search 来，完整流水线没有端到端学习候选框。
  3. Faster R-CNN：在共享特征图上加 Region Proposal Network (RPN) 预测前景与框偏移，ROI head 做最终分类和精修；可按 RPN 分类、RPN 回归、head 分类、head 回归四项损失解释。
  4. RoI Pooling vs RoI Align：前者量化坐标/分箱会错位；后者保留浮点坐标，以双线性插值采样，利于像素级任务如 Mask R-CNN。不要把 RoI Align 说成“消除了所有误差”。

Focal Loss $-\alpha_t(1-p_t)^\gamma\log p_t$；当 $p_t$ 大（易样本）时降低其权重，减轻大量简单背景的影响。IoU loss 常写 $1-\mathrm{IoU}$，无交集时对分离方向没有有用的定位梯度，因此引入 GIoU（最小外接框）、DIoU（中心距离）、CIoU（进一步考虑长宽比）。不能说 IoU “永远不可导”或“从来不能作损失”。详见计算手册。

4.3 YOLO 与曲线

YOLO 是单阶段检测：一次网络前向直接输出框、objectness 和类别分数，省去单独提候选框的两阶段过程。早期 YOLOv1 的 $S\times S$ 网格中，每格输出 $B$ 个框的 5 个量及 $C$ 个条件类概率，所以总维度 $S\times S\times(5B+C)$；不能直接用它描述所有 YOLO 版本。该版本由目标中心落入哪格决定负责格，密集小目标有局限。后续版本引入 anchors、多尺度等变化。课件图中的速度—精度权衡应按具体版本和数据集描述。

重要纠错：YOLOv1 的训练目标中 confidence 可包含与真值 IoU 的关系，但推理时没有真值框，不能拿“预测框与真值的 IoU”计算 class score。推理时使用预测得到的 objectness/confidence 与条件类概率组成类别分数。

YOLO 后续图示（课件 4，90–103 页）：YOLOv2 引入 Darknet-19、批归一化、anchor、pass-through 和多尺度训练等；课件强调每框类别预测与 v1 每格共享类别输出的区别。YOLO9000 用层级类别结构（WordTree）组织更多类别；YOLOv3 用 Darknet-53，并在多个尺度预测，有利于不同尺寸目标；YOLOv4 展示“bag of freebies”一类训练技巧，如 Mosaic 增强、DropBlock 等。记演进思路即可，不要把 YOLOv1 的 $7\times7\times30$ 公式机械套到后续版本。

Selective Search 与 AP 曲线：Selective Search 先把图切成小区域，不断按颜色/纹理/大小等相似性合并邻接区域，从合并过程取候选框；它不是端到端可学习的 RPN。Precision $=TP/(TP+FP)$，Recall $=TP/(TP+FN)$；按置信度扫描阈值得到 P–R 曲线，一类 AP 汇总曲线下的精度，mAP 再对类别求平均（有的基准还对多个 IoU 阈值平均）。判断 TP 需要预测类别正确且与尚未匹配的真值框 IoU 达阈值；同一真值通常不能让多框都算 TP。分数与 FPS 是不同维度，不可只看速度断言检测质量。

4.4 FCN、反卷积、U-Net

逐 patch 分类重复计算；Fully Convolutional Network (FCN) 在整图上产生空间特征并上采样为像素预测。Max unpooling 依靠池化时记录的最大值位置，把值放回对应位置，其余补零；转置卷积通过可学习核上采样，基本尺寸 $H_o=(H_i-1)S-2P+D(K-1)+\mathrm{output_padding}+1$。U-Net 是编码器—解码器结构，同尺度特征从编码器接到解码器并通常按通道拼接，补回细节；这和 ResNet 的逐元素相加残差不同。U-Net 结构图包含左侧下采样、底部瓶颈、右侧上采样及横向连接。

自然语言处理与多模态表示

5. NLP 基础（课件 5，约 2–52 页）

5.1 为什么“词编号”不是词义

自然语言存在歧义、同义、多义与词序。One-hot 维度等于词表大小，任意两个不同词正交，不能直接表达相似性。Bag of Words (BoW) 统计词频但丢词序；bag of bigrams 保留局部相邻关系但维度大且仍丢全局顺序。稀疏存储的索引/数值形式只节省空间，不会凭空增加语义。词嵌入通过训练把词映射到低维稠密向量，基础是分布式假设：上下文相似的词往往语义相关。词向量的类比 $king-man+woman\approx queen$ 是可能观察到的几何规律，非普适逻辑定律。

NLP 任务层次（课件 5，约 2–10 页）：分词/词性标注处理词层，句法分析处理“哪个词修饰哪个词”，语义理解和问答要结合上下文；语言模型学习序列概率，文本生成在此基础上逐词采样。词的歧义不是给每个词一个固定向量就能完全解决，后续 RNN/Transformer 用上下文生成随句子变化的表示。

5.2 Word2Vec 的预测方向

设词表 $V$、词向量维度 $d$，输入嵌入矩阵可按“行取向量”写 $E\in\mathbb R^{V\times d}$，输出矩阵 $U\in\mathbb R^{d\times V}$。中心词 $w_t$ 的窗口上下文记作 $C_t$。

  • CBOW：输入上下文，平均/求和其输入嵌入 $\bar v=|C_t|^{-1}\sum_{c\in C_t}E[c]$，softmax 预测中心词：$P(w_t\mid C_t)=\exp(u_{w_t}^\top\bar v)/\sum_{v\in V}\exp(u_v^\top\bar v)$。简单 CBOW 不编码上下文词的相对顺序。
  • Skip-gram：输入中心词，分别预测各上下文词，目标 $\sum_{c\in C_t}\log P(c\mid w_t)$。词表大时全 softmax 贵；工程上可用负采样近似训练：把真实词对判正，把采样噪声词对判负。这是补充理解，2026 课件此处主要讲 CBOW/Skip-gram 的预测方向。

纠错：softmax 输出是概率分布，不是“取最大后其他置 0 的 one-hot”；后者只是某种推断选词。两套嵌入矩阵在训练中角色不同。余弦相似度比较方向，$\cos(a,b)=a^\top b/(|a||b|)$，与欧氏距离不等价。

Word2Vec 图按维度读（课件 5，28–45 页）：令词表大小 $V$，输入 one-hot $x\in\mathbb R^V$，若采用列向量约定，$W_{\rm in}\in\mathbb R^{d\times V}$，则 $v=W_{\rm in}x\in\mathbb R^d$，等价于“查出该词的一列嵌入”。$W_{\rm out}\in\mathbb R^{V\times d}$ 将 $v$ 变为 $V$ 个 logit，softmax 才得到各词概率。CBOW 的上下文嵌入平均后再预测中心；Skip-gram 对每个上下文位置分别算预测损失，同一个中心词可对应多条正例。词向量中的 king–man+woman 类比显示某些语义差近似线性，但会受语料偏差、词频和多义影响。负采样将昂贵的全词表分类变为少量真实/噪声词对的二分类目标；采到的负词不保证语义真负。

5.3 概率语言模型

链式法则（精确）$P(w_{1:T})=\prod_{t=1}^TP(w_t\mid w_{1:t-1})$。$n$-gram 是近似马尔可夫假设：只看前 $n-1$ 个词。例如 bigram：$P(w_t\mid w_{1:t-1})\approx P(w_t\mid w_{t-1})$；trigram 才看前两个词。频数估计 $\hat P(w_t\mid h)=\mathrm{count}(h,w_t)/\mathrm{count}(h)$，未见组合会零概率，需平滑。困惑度 $\mathrm{PPL}=\exp[-T^{-1}\sum_t\log P(w_t\mid w_{<t})]$，在同一数据/分词口径下越低越好。务必注意：bigram 只看前一个词。

词袋与序列模型对比：BoW/bigrams 是句子的静态计数表示；$n$-gram 用频数估计下一个词的条件概率，历史窗口固定；神经 RNN 把历史压进隐藏状态，理论上可处理变长前缀，实际受优化与记忆瓶颈影响。Unigram 假设每个词独立，不利用前文；神经网络算一个词分布也不会自动获得上下文。计算 PPL 时先把各位置真词概率相乘或取平均 log，再取指数；不同分词器划分的 token 长度不同，PPL 不能随意横比。

6. RNN、LSTM 与序列训练（课件 5，约 53–128 页）

RNN：$h_t=\phi(W_xx_t+W_hh_{t-1}+b)$，$o_t=W_oh_t+b_o$，各时间步共享 $W_x,W_h,W_o$；输入/输出长度可变。Many-to-one 如情感分类，one-to-many 如图像描述，many-to-many 如序列标注/翻译。训练时 BPTT 在时间展开图上反传；链式相乘易使梯度消失或爆炸。若每一步雅可比矩阵范数持续小于 1，长链倾向衰减；大于 1 则可能放大，不能只看单个权重的一个数就保证结论。梯度裁剪常缓解爆炸，LSTM/GRU 改善长依赖。

Teacher forcing：训练生成器时用真实上一个 token 作为下一步输入；推理只能用模型自己生成的 token，存在 exposure bias。截断 BPTT 只在有限时间窗口反传，以节省计算/显存，并不从根本上解决长依赖，过短还会截断长期梯度。

Scheduled sampling（课件 5，约 96 页）：训练时逐步以一定概率改用模型自己生成的上一词作为下一步输入，以缩小训练和推理时的输入分布差异。它有自己的训练偏差与稳定性问题，不能保证消除 exposure bias。

展开计算图与解码（课件 5，78–107 页）：每个时刻都可有 $L_t$，总损失常为 $\sum_tL_t$；共享的 $W_h$ 在每个时刻使用，因此总梯度是各时间路径贡献的和。对末端损失，一条早期路径包含 $\prod_{j=k+1}^T\partial h_j/\partial h_{j-1}$，重复连乘解释梯度消失/爆炸。生成时贪心解码每步选最大概率词，采样按分布随机取词，beam search 同时保留有限个高分前缀；beam search 增宽搜索但不能保证语义正确。训练用 teacher forcing 时各时间步的真实前缀已知，推理时输出依赖先前生成结果。

LSTM 六个关键式子：

$$\begin{aligned}
f_t&=\sigma(W_f[h_{t-1};x_t]+b_f),&
i_t&=\sigma(W_i[h_{t-1};x_t]+b_i),\
\tilde c_t&=\tanh(W_c[h_{t-1};x_t]+b_c),&
c_t&=f_t\odot c_{t-1}+i_t\odot\tilde c_t,\
o_t&=\sigma(W_o[h_{t-1};x_t]+b_o),&
h_t&=o_t\odot\tanh(c_t).
\end{aligned}$$

$f$ 选择保留旧记忆，$i$ 选择写入候选，$o$ 控制读出；$c_t$ 是记忆通路，$h_t$ 是对外状态。加法更新让梯度存在直接路径，沿“保持其他门固定”的直接路径 $\partial c_t/\partial c_{t-1}=f_t$；完整导数还含门依赖，因此不能说 LSTM 永远没有梯度消失/爆炸。课件末尾图网络可记：节点表示通过邻居消息聚合、更新，图像区域/词可建关系图，层数越多感受邻居越远，也可能过平滑。

GNN 图示补充（课件 5，120–128 页）：图由节点集 $V$、邻接矩阵 $A$、节点特征 $X$ 和可选标签 $Y$ 构成。一个节点的新表示来自“自己的旧表示 + 邻居表示的聚合”，可写成示意式 $h_v^{(\ell+1)}=\phi(W_{\rm self}h_v^{(\ell)}+W_{\rm nbr}\operatorname{AGG}_{u\in\mathcal N(v)}h_u^{(\ell)})$。AGG 可取求和/平均/注意力，必须与邻居顺序无关。监督节点分类利用有标签节点的交叉熵；无监督图表示学习可利用图结构构造相似性目标。两层聚合使节点可感受两跳邻居，这一点可从课件递归图直接看出。

7.1 Representation 的三条路线

设图像特征 $a=f_A(x_A)$、文本特征 $b=f_B(x_B)$。Fusion 把多个模态合成一个联合表示 $z$，方便联合预测；Coordination 保留各自表示 $z_A,z_B$，通过相似/相关损失让配对样本可比较；Fission 将表示分成共享、模态私有等因素，使模型兼顾共性与个性。它们不是互斥类别，一个模型可同时融合与协调。

方式 算法直觉 优缺点
早期融合 输入/低层特征拼接、相加 容易捕获底层交互，但对时空不同步、尺度差异敏感
晚期融合 模态单独预测，再加权/投票 模态独立强，可能错过细粒度交互
拼接 $z=[a;b]$ 保留各自信息，但交互需后续层学习
加法 $z=a+b$（先维度对齐） 便宜，对不同来源的细粒度乘性交互表达弱
Hadamard 乘 $z=a\odot b$ 同位维交互，维度不变
双线性/张量 $h_k=a^\top W_kb$ 学全部成对交互，但参数可达 $d_hd_ad_b$
门控 $g=\sigma(W[a;b])$，$z=g\odot a+(1-g)\odot b$ 按样本学习哪个模态更有用

张量融合常先增广 $\tilde a=[1;a]$、$\tilde b=[1;b]$，再取外积：包含常数、单模态项及双模态交互。三模态可用三阶外积；维度乘积迅速变大。低秩分解 $W_k\approx\sum_{r=1}^R u_{k,r}v_{k,r}^\top$ 后，$h_k\approx\sum_r(u_{k,r}^\top a)(v_{k,r}^\top b)$，避免显式构造巨大外积；低秩是表达能力与成本的折中。注意 $a^\top b$ 是内积得到标量，$ab^\top$ 是外积得到矩阵。

7.2 协调、CCA 与 CLIP

协调损失可用欧氏距离、余弦、Pearson 相关、核相似度等；关键是“配对样本靠近，非配对样本可区分”，同时各模态保留可独立编码能力。

典型相关分析 CCA：对中心化随机向量 $X,Y$ 找投影 $u,v$，最大化

$$\rho(u,v)=\frac{u^\top\Sigma_{XY}v}
{\sqrt{(u^\top\Sigma_{XX}u)(v^\top\Sigma_{YY}v)}}.$$

约束 $u^\top\Sigma_{XX}u=v^\top\Sigma_{YY}v=1$ 可消除任意缩放。它最大化相关性而非直接最小化欧氏距离；普通 CCA 是线性投影，深度 CCA 用神经编码器扩展。相关系数介于 $[-1,1]$，协方差的大小则受尺度影响。

课件 6，约 55–58 页的变体图：DCCAE 把“让两个视图投影相关”的目标与“各自重建输入”的目标并用；前者鼓励共同信息，后者避免为了相关性而丢弃过多原始内容。多视图潜空间图表达先学习潜在共享空间再恢复/预测各视图。Gated coordination 则用门值调节两模态的相互作用。分析图示时，可先定位各编码器、共享与私有表示及解码器，再说明每项损失作用于哪条支路。

Pearson 与核函数（课件 6，38–47 页）：Pearson $\rho=\mathrm{Cov}(X,Y)/(\sigma_X\sigma_Y)$ 比协方差更能排除量纲差异；若 $Y=2X+3$ 且 $X$ 有方差，则 $\rho=1$。余弦比较两个向量相对原点的夹角，Pearson 比较中心化后的线性相关，二者不总相等。核相似度可写 $k(x,y)=\langle\phi(x),\phi(y)\rangle$；RBF 核 $k(x,y)=\exp[-|x-y|^2/(2\sigma^2)]$ 距离越近值越大。CCA 用协方差矩阵而非简单逐样本余弦优化，通常要中心化并约束投影方差；多对典型变量还要限制新方向与已有方向的相关，避免重复得到同一方向。

CLIP：图像编码器和文本编码器输出单位向量；批内 $N$ 对图文构造 $N\times N$ 相似度矩阵 $S_{ij}=v_i^\top t_j/\tau$，对角线是正确配对，其他位置通常作负例。图到文和文到图两个方向的交叉熵取平均：

$$L_{\rm i2t}=-\frac1N\sum_i\log\frac{e^{S_{ii}}}{\sum_j e^{S_{ij}}},\quad
L_{\rm t2i}=-\frac1N\sum_i\log\frac{e^{S_{ii}}}{\sum_j e^{S_{ji}}},\quad L=\tfrac12(L_{\rm i2t}+L_{\rm t2i}).$$

温度 $\tau$ 小，分布更尖锐。零样本分类把类别写成自然语言提示，将图像与各提示编码，按相似度选类，不需该任务专用分类头。公式易错：InfoNCE 必须有指数、归一化和负对数；批内“非配对”也可能语义相同，是潜在假负例。课件中的热力图：训练后对角线相似度应更突出，但不要把某一批图像的经验图当作数学保证。

CLIP 图的后半段（课件 6，约 60–62 页）：零样本分类并非直接拿“猫”“狗”两个孤立词当传统分类头，而是可写成“A photo of a cat”之类自然语言模板，分别编码类别文本，再与图像向量比较。不同模板可平均文本表示/分类分数，缓解提示措辞敏感。课件的跨数据集柱图和 few-shot 曲线展示迁移性能随数据集/示例数不同而变化；它们说明这种预训练表示具有迁移性，不能据此说“所有数据集零样本都优于专门监督模型”。CLIP 只在全图—文本级别对比训练时，也不自动给出词—区域的精细对齐。

7.3 Fission、信息论与自监督

信息量 $-\log p(x)$，熵 $H(X)=-\mathbb E\log p(X)$，条件熵 $H(Y|X)=-\mathbb E\log p(Y|X)$；互信息

$$I(X;Y)=H(X)-H(X|Y)=H(Y)-H(Y|X)
=\mathbb E_{p(x,y)}\log\frac{p(x,y)}{p(x)p(y)}.$$

共享表示希望保留跨模态共同信息；私有表示保留模态独有内容；重建损失检查信息是否仍可从表示恢复，判别损失检查下游任务，去冗余/解耦项限制重复信息。不是所有 fission 方法都机械地“让两个整模态表示越不相似越好”，否则可能丢掉最需要的共享语义。课件相关图示应按共享/私有支路与各损失连接来解释。

Fission 三个损失按图记（课件 6，约 64–67 页）：两个模态分别编码出私有表示 $z_A,z_B$ 和共享表示 $z_Y$。$L_1$ 是下游标签预测的判别损失；$L_2$ 是把表示解码回原始模态的生成/重建损失；$L_3$ 是对 $z_A,z_B,z_Y$ 施加分离先验或“no overlap”约束，帮助不同支路承担不同信息。具体论文实现的正则形式可以变化，阅读课件图时，需说明每个 $L_i$ 连接的支路及其作用；它们并不简单表示“A 和 B 完全无关”。

信息论图的三个极端（课件 6，68–74 页）：若 $X,Y$ 独立，$I(X;Y)=0$；若 $Y$ 由 $X$ 完全决定，$H(Y|X)=0$，$I(X;Y)=H(Y)$；若有共同信息又各有私有信息，互信息只衡量共同部分的统计依赖，不等于两模态的全部信息。跨模态共享表示可用“提高 $I(Z;X)$ 和 $I(Z;Y)$”表达保留两侧信息的愿望，但实际计算互信息很难，常用对比目标、变分界或重建代理。课件推导的 InfoNCE 互信息下界与负例数量有关，是给定估计框架内的关系，不应推断无限增大 batch 必定提升测试成绩。

自监督用数据自身构造训练目标：对比学习把同一对象的两种增强/图文配对作正例，其他作负例；遮蔽重建预测被遮住内容；蒸馏式方法让学生匹配教师输出。InfoNCE 与互信息有关系，但“batch 越大一定越好”不成立，受假负例、计算、优化影响。图示重点：正例如何形成、负例如何取、编码器是否共享、损失在哪个空间算。

跨模态对齐与基础模型

8. 对齐与图像描述（课件 7，约 2–30、77–97 页）

对齐是局部对应：句子中的“狗”对应图像里狗的区域，而整张图与整句话配对只是全局对应。硬对齐选择少数元素，软对齐给每个区域连续权重，后者可用常规反传。图像描述的无注意力模型先用 CNN 得到固定全图向量，再交给 RNN 解码器；随着句子增长，单个固定向量可能成为信息瓶颈。加注意力后，每个生成时刻 $t$ 用隐藏状态与各图像区域特征 $v_i$ 算分数 $e_{ti}$，$\alpha_{ti}=\operatorname{softmax}i(e{ti})$，上下文 $c_t=\sum_i\alpha_{ti}v_i$，再预测词。注意这里 $c_t$ 通常叫视觉上下文向量，不要和 LSTM 的 cell state $c_t$ 混淆，为避免符号混淆，可用 $g_t$ 表示视觉上下文。

课件的注意力热图说明生成不同词时关注区域变化。注意力权重可帮助解释模型，但热图不必然等于人类语义解释。图像描述评价常用 BLEU、METEOR、CIDEr、SPICE 等：基于词/短语重叠或语义结构的自动指标可比较大量样本，但同义表达和事实错误可能使自动分数与人判断不同。课件中的失败案例包括遗漏对象、误判关系或属性，以及生成通顺却与图像不符的描述。

课件 7，约 78–96 页的视觉案例：格点特征注意力使用 CNN feature map 的位置，region attention 使用检测器给出的候选物体区域；后者更贴近“物体”但受检测器漏检/误检影响。课件的失败图把“物体识别不准”和“物体关系说错”分开：改进检测器只针对前者，后者需建模语义关系（如骑、拿）和空间关系（如左/上/内）；图网络可在区域之间传播关系信息。Dense image captioning 要为多个局部区域分别描述；video captioning 还要汇总时间信息；dense video description 则需输出事件起止时间与描述。评价指标要分清：BLEU 偏 n-gram 精确率，METEOR 考虑词匹配与顺序，CIDEr 用 TF-IDF 强调有辨识力的 n-gram，SPICE 比较场景图元组的 F1；单个指标不能代替人工事实核查。

对齐与转换的关系：局部区域—词的对齐帮助图像到文字的转换，但图像描述输出是完整语言序列，还要决定词序、关系和是否停止。无注意力的 CNN→RNN 可把图像向量用于初始化 $h_0$ 或在每步输入；有注意力的模型在每步重新取视觉上下文。soft attention 的权重是可微概率分布；hard attention 的离散选取通常需要特殊估计或强化学习式训练，不能直接按连续 softmax 路径求普通梯度。课件 4–10 页还强调上下文化表示：一个词/区域的表征应依赖所在句子/图像及另一模态的上下文，而非永远使用固定词向量。

9. Self-attention 与 Transformer（课件 7，约 31–76 页）

9.1 一遍看懂 Q、K、V

输入 $X\in\mathbb R^{T\times d_{\rm model}}$，$Q=XW_Q$、$K=XW_K$、$V=XW_V$。对每个 query，和所有 key 算匹配分数，沿 key 维 softmax，再加权求 value：

$$A=\operatorname{softmax}_{\rm row}\left(\frac{QK^\top}{\sqrt{d_k}}+M\right),\qquad Z=AV.$$

若 $Q\in\mathbb R^{T_q\times d_k}$、$K\in\mathbb R^{T_k\times d_k}$、$V\in\mathbb R^{T_k\times d_v}$，则 $A\in\mathbb R^{T_q\times T_k}$、$Z\in\mathbb R^{T_q\times d_v}$。输出 token 数由 query 决定。$\sqrt{d_k}$ 缩放避免点积随维数增大导致 softmax 过尖锐。mask 中不可见位置加 $-\infty$，softmax 后权重为 0；自回归因果 mask 禁止位置 $t$ 看 $>t$ 的未来位置。

自注意力 Q/K/V 来自同一序列；交叉注意力 Q 来自当前解码序列，K/V 来自编码器/另一模态。多头把特征投到多个子空间，各头独立算注意力，拼接后投影；通常 $d_{\rm model}=H d_{\rm head}$，不是“头数等于 $d_{\rm model}$/头数”。完整自注意力对 $T$ 个 token 的分数矩阵是 $T^2$，内存通常随 $T^2$ 增长。

为什么缩放、为什么多头：若 Q/K 每维独立、均值近零、方差约 1，点积方差随 $d_k$ 近似线性变大；除以 $\sqrt{d_k}$ 可把分数尺度控制在较稳定范围，减少 softmax 饱和。每个 head 有各自 $W_Q,W_K,W_V$，可以在不同投影子空间关注不同关系；这只提供能力，不保证每头自动学到人可解释的独立语法关系。若 $d_{\rm model}=Hd_{\rm head}$ 且 Q/K/V/输出投影均为完整矩阵，注意力线性投影的参数数量约 $4d_{\rm model}^2$（忽略 bias），头数变化并不必然同比增加参数总数。

9.2 顺序、位置编码与架构

不加位置线索时，self-attention 对输入 token 的置换具有等变性：重排输入，输出也相应重排；不能严格说输出“完全不变”。绝对位置编码可与 token embedding 相加；经典正弦式为

$$PE_{(pos,2i)}=\sin!\left(pos/10000^{2i/d}\right),\qquad
PE_{(pos,2i+1)}=\cos!\left(pos/10000^{2i/d}\right).$$

课件架构图：Encoder 层是多头 self-attention + 前馈网络（FFN/MLP），每子层配残差与规范化；Decoder 多一个对 Encoder 输出的 cross-attention，自己的 self-attention 加因果 mask。LayerNorm 是每个 token 的特征维归一化；FFN 对每个位置用共享参数单独变换。训练机器翻译可以并行处理目标句位置，但因果 mask 防止未来泄露；生成推理逐 token 产生，仍具有顺序依赖。

位置编码为何要正弦/余弦（课件 7，46–49 页）：一对正弦余弦可表示平面上的旋转；移动固定距离会对每个频率对应一组确定的旋转变换，因此相对位置信息可从编码之间的关系中读出。对成对的同频率维度，$PE(pos)\cdot PE(pos+\Delta)$ 的贡献为 $\cos(\Delta/\omega)$，只依赖位移 $\Delta$；这解释课件“点积与偏移相关”的曲线。不同频率让近距离和远距离位置均有区分。加入位置编码前，self-attention 对重排是置换等变；加入后，模型才有机会区分顺序。课件标题写“permutation invariant”是通俗描述，严格讨论每个位置的输出时应用“等变”。

10. ViT、BERT、GPT、GQA、LoRA（课件 8，约 3–71 页）

10.1 ViT 与增强/蒸馏

把 $H\times W\times C$ 图像切为 $P\times P$ patch，若整除，patch 数 $N=HW/P^2$；每个 patch 展平后长度 $P^2C$，线性投影到 $d$ 维，加位置编码，可加 CLS token，然后送 Transformer Encoder。注意 patchify 本身不保证视觉局部先验；与 CNN 相比 ViT 对数据规模、增强和训练策略更敏感。课件比较曲线表明给定实验设置下大规模预训练与增强显著改善 ViT，不能推出任意预算下都优于 CNN。Token 数增大使全局注意力矩阵约为 $(N+1)^2$。ViT/DeiT 的蒸馏图：teacher 的软目标指导 student，distillation token 提供一条输出支路；推理与训练用法看具体模型，不把“蒸馏=标签平滑”混为一谈。

蒸馏曲线逐项读（课件 8，约 28–36 页）：先用真标签训练 teacher，再让 student 通过 KL 散度匹配 teacher 的软预测，也可混合对真标签的交叉熵。温度 $T$ 越大，softmax(logits/$T$) 越平滑；若用经典蒸馏目标，KL 项常乘 $T^2$ 以平衡梯度尺度。课件柱图依次加入蒸馏、延长训练、提高输入分辨率，因此最后一柱相对第一柱的提升不能全归因于蒸馏。第 34 页的 distillation token 与 classification token 是两条不同输出支路，均参与 Transformer 处理。

10.3 LLaMA、GQA、LoRA 与多模态 LLM

LLaMA 相关课件强调数据、模型规模及推理效率。多头注意力 (MHA) 每个 query 头通常有独立 K/V 头；Multi-Query Attention (MQA) 让所有 Q 头共享一组 K/V；Grouped-Query Attention (GQA) 把 Q 头分组，每组共享一组 K/V，降低 KV cache。它们是推理缓存与表达能力之间的设计取舍。

课件 8，约 43–67 页的模型发展线：GPT-1 展示生成式预训练加下游适配；GPT-2 强调用自然语言任务描述进行条件生成；GPT-3 展示大模型的 in-context few-shot 提示。它们的核心仍是因果下一 token 预测，具体训练规模和任务适配方式逐代变化。LLaMA 课件图列出 Decoder、RMSNorm、SiLU/Swish 和 RoPE（旋转位置编码）；RoPE 给 Q/K 注入位置关系，不能简单等同于“输入 token 加一条绝对位置向量”。LLaMA 2/3 图强调更长训练、GQA 和指令微调等演进；年份与数值对比只在课件所列实验条件下理解。

课件第 54 页把 GPT-4 作为后续大模型进展的例子；阅读相关比较时，应区分课件明确展示的内容与未提供的训练细节。

LoRA 冻结原权重 $W\in\mathbb R^{d_{\rm out}\times d_{\rm in}}$，只学习低秩增量 $\Delta W=BA$，其中 $B\in\mathbb R^{d_{\rm out}\times r}$、$A\in\mathbb R^{r\times d_{\rm in}}$。可训练参数 $r(d_{\rm out}+d_{\rm in})$（忽略缩放/bias），相对全量 $d_{\rm out}d_{\rm in}$ 显著变小；常让一因子初始化为零，使开始时 $\Delta W=0$。公式位置和转置取决于 $W$ 约定，维度相乘正确最重要。多模态 LLM 常见链路：视觉编码器 → 投影/连接器使视觉 token 匹配语言模型维度 → 与文本 token 共同输入语言模型 → 指令微调生成回答。课件最后 68–71 页只给入门，别把某一具体连接方式当成所有视觉语言模型的唯一结构。
