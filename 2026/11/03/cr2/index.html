北京大学《认知推理》（2026 秋）的课程笔记。

这一讲的课件叫 The Training Stack。它把从最小二乘到大语言模型的工程问题串起来：模型为什么这样设计？参数怎样更新？算力与数据预算又怎样分配？

先弄清我们究竟在优化什么

有训练样本 $(x_i,y_i)$，先选函数族 $f_\theta$ 和损失 $\ell$。真正关心的是未知分布上的风险 $R(\theta)=\mathbb E[\ell(f_\theta(x),y)]$，但我们只有有限样本，于是优化经验风险 $\hat R(\theta)=\frac1n\sum_i\ell(f_\theta(x_i),y_i)$。

模型选择、优化和泛化是三件事。换一个网络结构，是改变可表示的函数；换优化器，是改变找参数的路径；验证集表现好坏，才接近我们最关心的泛化问题。

回归输出连续值，常用平方误差。分类输出离散标签，若要训练概率，可对 logits 使用 sigmoid 或 softmax，再最小化交叉熵。课件把它们画成“共享的特征主体 + 不同输出层”，这样同一种表示可以服务不同任务。

从线性层开始：为什么需要正则化

最小二乘目标 $J(w)=\frac12|Xw-y|_2^2$ 的梯度是 $X^T(Xw-y)$。令它为零得到正规方程 $X^TXw=X^Ty$。

如果特征太多，或几列几乎重复，$X^TX$ 可能不可逆或病态。稍微改变训练标签，就可能得到差别很大的权重。

加上 $\frac\lambda2|w|_2^2$ 后，方程变为 $(X^TX+\lambda I)w=X^Ty$。从特征值看，$\lambda I$ 抬高了接近零的特征值，使问题更稳定。实现时应解线性方程，不必真的形成逆矩阵。

Logistic 回归没有相应的闭式解，但其负对数似然对线性参数是凸的，可以用梯度下降。Softmax 对所有 logits 同加一个常数不会改变概率，数值实现就先减去最大 logit，再求指数，避免溢出。

MLP、CNN、RNN、Transformer 分别改变了什么

MLP 在线性层之间插入非线性。如果没有激活函数，多层线性变换仍等价于一层。反向传播把损失对输出的导数逐层传回去，每层的权重梯度由“该层误差信号 × 输入激活”构成。

CNN 让局部卷积核在图像空间共享。直接把 $224\times224\times3$ 图像接到 1000 个隐单元，第一层约需 1.5 亿个权重；局部共享能大幅减少这个数。连续三个步长 1 的 $3\times3$ 卷积，理论感受野从 3 扩到 5 再到 7。参数共享是它适合图像的关键假设。

RNN 在不同时间步共享递推矩阵，能够处理变长序列。但反向传播需要穿过许多时间步，反复相乘的 Jacobian 会使梯度消失或爆炸。LSTM 用遗忘门、输入门和输出门控制记忆：$c_t=f_t\odot c_{t-1}+i_t\odot\tilde c_t$，让重要信息有更直接的传递路径。

注意力 让当前查询直接读取各位置的信息。先计算 $e_j=q^Tk_j/\sqrt{d_k}$，用 softmax 得到权重 $\alpha_j$，再求 $\sum_j\alpha_jv_j$。多头注意力同时学习几种读取方式。Transformer 把注意力与逐位置前馈网络交替堆叠，用位置编码保留顺序，用残差和归一化帮助深层训练。

梯度下降、AdamW 和训练稳定性

在当前参数附近，$L(\theta+\Delta)\approx L(\theta)+g^T\Delta$。如果限制步长的二范数，负梯度是局部下降最快的方向，于是得到 $\theta_{t+1}=\theta_t-\eta g_t$。

批量梯度用全部样本；小批量梯度噪声较大，但每一步便宜且适合 GPU。AdaGrad 累加每个坐标的历史平方梯度，稀有特征可获得较大更新；因为累加量单调增长，步长会不断变小。RMSProp 与 Adam 改用指数滑动平均。Adam 同时跟踪梯度的一阶和二阶矩，并需要偏差修正，否则训练初期的统计量会系统性偏小。

为什么常用 AdamW？若把 $L_2$ 惩罚直接加进 Adam 的梯度，惩罚也会被坐标自适应分母缩放；AdamW 将权重衰减单独执行，使收缩不依赖该坐标的历史梯度。学习率预热、后续衰减、全局梯度范数裁剪，是避免初期不稳定和偶发异常 batch 的常见配套措施。

初始化也很重要。若每层输出方差都乘上同一个因子，堆叠几十层后就会指数式放大或缩小。ReLU 约屏蔽一半输入，He 初始化据此选权重方差约 $2/n_{in}$。BatchNorm 训练时使用 batch 统计、推理时使用累计统计；LayerNorm/RMSNorm 按每个 token 的特征维归一化，不依赖同一批次的其他样本。

数据、计算与大模型的额外问题

文本进入模型前要先切成 token。BPE 从较小单位开始，反复合并语料中高频的相邻符号。常见词可能合成一个 token，罕见词由子词拼成。词表越大，序列可能越短，但嵌入与输出层越大；分词还会影响数字、字符计数和不同语言的使用成本。

在固定算力 $C$ 下，模型参数量 $N$ 与训练 token 数 $D$ 不能都无限增加。课件用 $L(N,D)\approx E+AN^{-\alpha}+BD^{-\beta}$ 表示两种不足：模型太小会欠表达，数据太少会训练不足。实际会在几个小规模配置上做预算相同的实验，再推断较合适的规模，而不是只盯住单次训练的最小 loss。

混合专家模型（MoE）让每个 token 只调用少数几个前馈网络。总参数数目可随专家数增长，而每个 token 的活跃计算量主要由选中的专家数决定。但路由器可能只偏爱少数专家，因此要考虑负载均衡、专家容量和跨设备通信。

模型放不进单卡时，还可采用数据并行、张量并行、流水线并行，以及参数/优化器状态切分。数据并行复制模型并汇总梯度；张量并行切开一层的矩阵；流水线并行把不同层放在不同设备。它们节省的资源不同，通信与空闲等待的代价也不同。激活检查点和混合精度常先用来降低内存压力。

反向传播与归一化再细看一步

设一层输出 $h=\phi(Wx+b)$，上游传回 $\delta_h=\partial L/\partial h$。先经过激活函数得到 $\delta_z=\delta_h\odot\phi’(Wx+b)$，于是 $\partial L/\partial W=\delta_zx^T$、$\partial L/\partial b=\delta_z$，再把 $W^T\delta_z$ 传给前一层。自动微分只是把这一链式法则沿计算图系统执行。

深层网络里要特别留意信号尺度。若每层都使激活方差乘以 $1.1$，几十层之后偏差会累积；ReLU 又会截去一半负输入，因此初始化方差需要相应补偿。归一化层可进一步稳定中间表示，但不能代替检查学习率和数据输入是否正确。

对形状 $(B,T,d)$ 的序列张量，LayerNorm 通常分别对每个 batch、每个位置的 $d$ 个特征求均值和方差；RMSNorm 只按特征均方根缩放。它们不依赖同一 batch 中其他样本，因此在变长序列和单样本推理时使用方便。

分词给模型设定了“基本单位”

拿一个罕见词做例子。按整个词建词表，没见过的词无法表示；按字符拆，序列会很长。BPE 从字符或字节出发，把语料中频繁一起出现的相邻符号逐步合并：常见词或词缀会变成较短的 token 序列，罕见词仍可由小单位拼出来。

但 token 是人为选出的单位，不等于自然语言的“真正词”。数字 1000 与 1,000 可能被切成完全不同的序列；英语语料占主导的词表，也可能让其他语言付出更多 token 成本。这些偏差发生在模型训练之前，后续扩大参数未必能完全消除。

算力预算下怎样取舍

对密集 Transformer，粗略的训练计算量常写成 $C\approx6ND$，$N$ 是参数量，$D$ 是训练 token 数。给定预算 $C$，参数多一点意味着可处理的 token 通常要少一点。

如果模型太小，即使见过很多数据也难以表达复杂分布；如果模型很大却只看少量 token，又容易训练不足。课件用损失的经验标度关系比较这两种不足。实际做法是先在较小规模上训练多个配置，观察相同计算量下哪组最优，再谨慎外推；标度律是经验拟合，不能当物理定律。

MoE 给出了另一种取舍：参数可以分散在许多专家里，单个 token 只激活其中少数。它节省活跃计算，但没有免费午餐。专家权重仍需存储，路由器可能负载不均，跨设备分发 token 需要通信；如果某个专家容量不够，还可能溢出或丢弃部分 token。

这讲内容很多，可以把它当一张地图：架构决定怎么表示，损失与优化器决定怎么学，数据与系统设计决定在给定预算下能学到多少。后面的认知推理专题会在这张工程地图上，进一步问模型是否真正理解动作、物理与因果。
