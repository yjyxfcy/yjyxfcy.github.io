复习这一讲的时候我的感受是：它把第 1 讲五大挑战里的“对齐”落到了一个具体机制上——注意力。老师从“图像里的区域怎么对应句子里的词”这个问题出发，先讲图像描述里固定向量的瓶颈，引出 Show, Attend and Tell 的视觉注意力，再一步步把通用注意力层拆成 Q/K/V、自注意力、位置编码、mask、多头，组装成 Transformer，末了回到图像描述的区域、关系、基准和未来。我复习时抓的钩子是“对齐是目标，注意力是手段，Transformer 是把手段做成可扩展的架构”。公式和手算例题一步不省，也记一下我自己卡过的地方，尤其是 dk\sqrt{d_k}dk​​ 到底为什么除、以及置换“等变”和“不变”的区别。

对齐与上下文化表示：为什么需要注意力

对齐的定义

课件给对齐下的定义：识别并建模多个模态所有元素之间的跨模态连接，从数据结构出发。它分离散对齐（离散元素与连接）和连续对齐（分割与连续 warping），又和表示纠缠在一起。课件点了隐式对齐：不直接标对应，而是靠模型内部潜在的模态对齐来更好地解题——注意力就是隐式对齐的主力。自己补的区分：句子里的“狗”对应图里狗的区域是局部对应，整张图与整句话配对只是全局对应；硬对齐选少数元素，软对齐给每个区域连续权重、可用常规反传。

上下文化表示的三条路

课件问“怎么编码序列、同时建模元素间的交互”，给了三个选项对比：

  • Bi-LSTM：能建模交互，但顺序计算、难并行。
  • 卷积：能并行，但滤波器是静态的，建模长程依赖要堆很多层。
  • 自注意力：并行计算 + 长程依赖 + 动态注意力权重，三样都占。

这张对比表我觉得是理解“为什么 Transformer 取代 RNN”的钥匙。课件顺势引出 Transformer 的零件：self-attention、multi-head、position embeddings、seq2seq。

图像描述的瓶颈与注意力

课件拿 Show, Attend and Tell（Xu et al., ICML 2015）讲注意力的来历。无注意力模型先用 CNN 得一个固定全图向量 ccc，再交给 RNN 解码；课件点了死穴：输入被“瓶颈”在 ccc 里，模型想说的 everything 都得塞进这一个向量，要生成很长的描述怎么办？课件的解法：每个时间步用一个新上下文向量，各自注意不同的图像区域。具体地，生成时刻 ttt 用隐藏状态与各区域特征 viv_ivi​ 算分数 etie_{ti}eti​，αti=softmax⁡i(eti)\alpha_{ti}=\operatorname{softmax}_i(e_{ti})αti​=softmaxi​(eti​)，视觉上下文 ct=∑iαtivic_t=\sum_i\alpha_{ti}v_ict​=∑i​αti​vi​，再预测词。课件强调整个过程可微，模型自己选注意力权重，不需要注意力监督。课件区分 soft attention（权重是可微概率分布）和 hard attention（离散选取，需特殊估计或强化学习式训练，不能直接走连续 softmax 的普通梯度）。自己补的易错点：这个视觉上下文 ctc_tct​ 和 LSTM 的 cell state ctc_tct​ 重名，我记笔记时改用 gtg_tgt​ 表示视觉上下文，免得混。

注意力机制：从通用层到 Q/K/V

通用注意力层

课件把注意力抽象成一个通用层。课件注明注意力操作是置换不变的，不在乎特征顺序，把 H×W=NH\times W=NH×W=N 展平成 NNN 个向量即可。课件把对齐函数 fattf_{\rm att}fatt​ 换成缩放点积；课件说有多个 query 向量，每个 query 产生一个新的输出上下文向量。

为什么除 √d_k

课件给了缩放的推理链，我抄成因果链：维度大 → 点积求和项多 → logits 方差更高 → 大幅值向量产生很高的 logit → softmax 变尖、给其他位置极少权重 → 除以 D\sqrt{D}D​ 削弱大幅值的影响。手册的尺度直觉：若 Q/K 各维均值 0、方差 1 且近似独立，点积 q⊤k=∑j=1dkqjkjq^\top k=\sum_{j=1}^{d_k}q_jk_jq⊤k=∑j=1dk​​qj​kj​ 的方差约 dkd_kdk​，除 dk\sqrt{d_k}dk​​ 后方差约 1。自己补的备注：这是尺度直觉，真实网络不必严格独立。

Q/K/V 与自注意力

课件关键一步：输入向量本来同时用于对齐和注意力计算，在两步前各加一个不同的 FC 层就增加了表达力，于是有了 Q、K、V 三套投影；输入输出维度可随 key/value 的 FC 层改变。课件的自注意力更进一步：不再要外部 query，query 也从输入向量算，Q/K/V 来自同一序列。公式摆齐：

Q ⁣: Tq×dk,K ⁣: Tk×dk,V ⁣: Tk×dv,Q\!:\ T_q\times d_k,\quad K\!:\ T_k\times d_k,\quad V\!:\ T_k\times d_v, Q: Tq​×dk​,K: Tk​×dk​,V: Tk​×dv​,

S=QK⊤dk+M ⁣: Tq×Tk,A=softmax⁡row(S),Z=AV ⁣: Tq×dv.S=\frac{QK^\top}{\sqrt{d_k}}+M\!:\ T_q\times T_k,\quad A=\operatorname{softmax}_{\rm row}(S),\quad Z=AV\!:\ T_q\times d_v. S=dk​​QK⊤​+M: Tq​×Tk​,A=softmaxrow​(S),Z=AV: Tq​×dv​.

输出长度由 Q 决定。手册手算例我重算过：一个 query 对两个 key 的缩放后分数 (0,ln⁡3)(0,\ln3)(0,ln3)，values v1=(2,0),v2=(0,4)v_1=(2,0),v_2=(0,4)v1​=(2,0),v2​=(0,4)，权重 (1/4,3/4)(1/4,3/4)(1/4,3/4)，输出 (.5,3)(.5,3)(.5,3)；若第二位置被 mask，分数变 (0,−∞)(0,-\infty)(0,−∞)，权重 (1,0)(1,0)(1,0)，输出 (2,0)(2,0)(2,0)——先按行 softmax，再乘 V。维度例 Tq=3,Tk=5,dk=4,dv=6T_q=3,T_k=5,d_k=4,d_v=6Tq​=3,Tk​=5,dk​=4,dv​=6：QK⊤QK^\topQK⊤ 是 3×53\times53×5，ZZZ 是 3×63\times63×6，交叉注意力输出序列长 3。自注意力 Q/K/V 同源，交叉注意力 Q 来自当前解码序列、K/V 来自编码器或另一模态。若 dmodel=Hdheadd_{\rm model}=Hd_{\rm head}dmodel​=Hdhead​ 且四个投影都是完整矩阵，注意力线性投影参数约 4dmodel24d_{\rm model}^24dmodel2​（忽略 bias），头数变化不必然同比增加参数。

位置、mask 与多头：把顺序和结构补回来

位置编码

课件提出一个问题：自注意力置换不变，怎么编码语言或图像特征这种有序序列？答案是位置编码。经典正弦式：

PE(pos,2i)=sin⁡ ⁣(pos/100002i/d),PE(pos,2i+1)=cos⁡ ⁣(pos/100002i/d).PE_{(pos,2i)}=\sin\!\left(pos/10000^{2i/d}\right),\qquad PE_{(pos,2i+1)}=\cos\!\left(pos/10000^{2i/d}\right). PE(pos,2i)​=sin(pos/100002i/d),PE(pos,2i+1)​=cos(pos/100002i/d).

例 pos=0pos=0pos=0：偶数维全 0、奇数维全 1。课件问“为什么要 sin 和 cos”：不只要绝对位置，还要相对位置；同频率一对 sin⁡(pos/ω),cos⁡(pos/ω)\sin(pos/\omega),\cos(pos/\omega)sin(pos/ω),cos(pos/ω) 的两个位置点积为 cos⁡((pos−pos′)/ω)\cos((pos-pos')/\omega)cos((pos−pos′)/ω)，只由相对位移决定，而且点积无向。这解释了课件“点积与偏移相关”的曲线。自己补的两点：严格说纯自注意力对 token 置换是等变（重排输入、输出相应重排），不是“输出完全不变”，课件标题写 permutation invariant 是通俗说法；RoPE 的思路是在 Q/K 的二维子空间按位置角度旋转，让点积自然依赖位置差，和“给输入直接加绝对位置向量”不是同一操作。

Masked self-attention 与多头

课件的 masked self-attention 防止向量看未来：手动把对齐分数设成 −∞-\infty−∞，softmax 后权重为 0；自回归因果 mask 禁止位置 ttt 看 >t>t>t 的位置。课件的多头把特征投到多个子空间，各头独立算注意力再拼接投影；通常 dmodel=Hdheadd_{\rm model}=Hd_{\rm head}dmodel​=Hdhead​（例 512、8 头 → 每头 64），每头有各自的 WQ,WK,WVW_Q,W_K,W_VWQ​,WK​,WV​，能在不同子空间关注不同关系。自己补的提醒：这只提供能力，不保证每头自动学到人可解释的独立语法关系；完整自注意力对 TTT 个 token 的分数矩阵是 T2T^2T2（T=1000T=1000T=1000 就是 10610^6106/头），内存通常随 T2T^2T2 涨。

Transformer 架构与 RNN 对比

课件组装 Transformer。Encoder 层是多头 self-attention + 前馈网络（FFN/MLP），每个子层配残差与 LayerNorm；Decoder 多一个对 Encoder 输出的 cross-attention，自己的 self-attention 加因果 mask。LayerNorm 是每个 token 在特征维归一化，FFN 对每个位置用共享参数单独变换。课件对比 RNN 与 Transformer：训练机器翻译可并行处理目标句位置（因果 mask 防未来泄露），生成推理仍逐 token、有顺序依赖。课件的总结我记成：Transformer 用 self-attention + layer norm，高可扩展、高可并行，训得更快、模型更大、视觉语言任务都更好，正在迅速取代 RNN/LSTM，甚至可能取代卷积。课件还问“图像描述还需要 CNN 吗”，引出从像素直接到语言的 Transformer。

图像描述的训练、解码与评价

训练目标与解码策略

图像描述训练通常最小化真实下一个词的负对数似然 −∑tlog⁡p(wt∣w<t,I)-\sum_t\log p(w_t\mid w_{<t},I)−∑t​logp(wt​∣w<t​,I)。训练时可并行用真实前缀（teacher forcing），推理时后续词未知、只能把已生成的词喂回。解码三种：贪心每步取最大概率词、beam search 同时保留若干高分前缀、采样保留随机性。自己补的提醒：它们改的是搜索策略，并没有替模型补上缺失的视觉事实。

基准与评价指标

课件给基准：COCO Captions（Chen et al., 2015）train/val/test = 113k/5k/5k、隐藏测试 40k、词表（≥5 次）9587，最常用；Flickr30k 29k/1k/1k、词表 6864。课件的四个自动指标我整理成表：

指标 怎么算 侧重
BLEU n-gram 精确率 词/短语重叠
METEOR unigram 匹配、对顺序敏感 匹配与词序
CIDEr TF-IDF 给重要 n-gram 更高权重 有辨识力的 n-gram
SPICE 场景图元组的 F1 语义结构

三层问题分开看

我复习时特意把三层分开：训练目标考察参考句概率，自动指标比较候选与参考的重叠/结构，人类评测还要看物体、属性、关系是否真实存在。同义表达和事实错误都会让分数与人的判断不一致，不能混成“分数高，所以模型看懂了图像”。注意力热图能看出生成不同词时模型注意哪些区域，有助分析，却不等同于人类的语义解释。

图像描述进阶与收尾

区域注意力与失败案例

课件讲失败与改进。视觉注意力可落在两种特征上：格点注意力用 CNN feature map 的位置，region attention 用检测器（Faster R-CNN）给的候选物体区域，后者更贴近“物体”却受漏检误检影响。课件把失败分两类：物体认得不准和关系说错。改进检测器只能解决前者，后者还要建模关系。

关系建模与层次解析

课件（Yao et al., ECCV 2018）把语义关系（Visual Genome 的 20 类，如“骑、拿”）和空间关系（11 类，如“左、上、内”）整合进图像描述，用 GCN 在区域间传播关系、学更有信息量的区域感知表示。课件还有层次解析：从实例级（分割）到区域级（检测框）再到整图。这把第 5 讲的图神经网络和第 4 讲的检测分割都接上了。

其他任务与未来

课件列了相关任务：dense image captioning（多区域分别描述）、novel object captioning（118K/1.9M 图）、multi-style captioning、video captioning（方法上几乎没差别，时间信息用不同方式汇总）、dense video description（输出事件起止时间+描述的三元组，通常含 event proposal 和 video description 两个模块）。课件的未来方向我记成：离生产可用还远，因为识别失败、物体幻觉、模型偏差；需要更好的特征、更好的 grounding/检测、缓解偏差，需要与人类判断更相关的评价指标，以及可解释性和泛化。

我自己的收尾理解是：这一讲把“对齐”从一个抽象挑战变成了可计算的注意力权重，再把注意力做成 Transformer 这个可扩展架构。soft attention 让模型自己学“看哪儿”，Q/K/V 让对齐和取值解耦，位置编码和 mask 把顺序补回来，多头让不同子空间关注不同关系。复习时我抓的钩子是：看到一个注意力模型，先问 Q/K/V 各来自哪（自注意力还是交叉注意力）、有没有 mask、位置怎么编码、输出长度由谁定——比背架构图可靠得多。这些零件到第 8 讲会直接组装成视觉语言基础模型，跨模态注意力正是把“眼睛”和“嘴巴”接起来的那根线。
